# Orange UI native regression

This standalone instrumentation package targets `cc.huevia` version 84 on task-owned `emulator-5582` only. It derives the incumbent local-album regression harness without modifying historical tests or evidence. The local-album scope runs the real permission, private import, editor, batch, version/publication reuse and structural RAW paths, followed by the new native UI flow.

The orange flow checks actual root navigation and adaptive bar/rail, template-rendered presets, NCP detail and nine native slots, a real second overwrite dialog cancelled before writing, NP3's local-album destination, sync sources/live, settings/Wi-Fi/account/update rendering, editor canvas stability and crop. Camera slots use typed synthetic observations and never write to hardware. All account/update operations are offline reads. Seed assets are existing test sources; no design-board raster is shipped in the app.

```powershell
tests/orange-ui-device-probe/build.ps1 -ExpectedVersion 84 -Scope local-album
tests/orange-ui-device-probe/matrix.ps1
```

The matrix builds/signs/installs the candidate, records source hashes before/after and repeats one regression scope in five configurations. Assertion execution totals are repeated checks, not independent scenarios. Tablet uses an ephemeral 1280×1800 / 240dpi override; the runner restores appearance/font/rotation and the matrix resets its size override. Native captures and JSON reports are written to `docs/validation/orange-ui-84/local-album/<mode>/`.

External permission/file-picker rendering, real sensors/cameras, live network catalogue, login/submission mutations, physical performance, color calibration, edge-swipe gestures and TalkBack certification are outside this fixture run. The inherited harness contains other legacy scopes for context; only the recorded `local-album` scope is exercised here.
