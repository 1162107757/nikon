## 已审改动与关闭问题

- 新增指定相机 SSID 的用户授权请求；权限回调、取消、Activity 销毁及旧 ticket／generation 均有失效检查。密码禁止保存到偏好和视图状态，禁用自动填充，仅保存 SSID。
- 已关闭 P2：系统 onAvailable 后、业务成功交接前点击取消可能保留网络请求。`deliveryPending` 使同 token 取消覆盖该窗口并丢弃排队成功回调；完成交接后的健康连接仍由服务持有。
- onLost 使旧无线 owner、handoff、相册及直播网络状态失效，不取消本地照片处理／保存或 USB lease；保留丢失路由 guard，不自动重连或回退到其他同地址热点。显式 USB 切换清理无线请求，已失效的旧 token 不释放新请求。
