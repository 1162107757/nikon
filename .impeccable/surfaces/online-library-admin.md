# 预设与用户管理后台

此管理工具沿用 `DESIGN.md` 的云白、石墨与蓝色角色及现有 web token。用户明确要求左侧菜单、右侧展示内容，结构直接按此扩展；不更改原生 Android 导航或品牌世界。

桌面固定侧栏提供“预设管理”“用户管理”两个真实目的地，宽 232px；761–1150px 为 204px。顶部保留账号、退出及外观选择；内容区用紧凑工具栏与列表承载操作。760px 及以下将侧栏转为 72px 顶部工具区下的横向导航，列表按行重排，外观与退出保持可达。内容左右留白通常为 20px，380px 及以下为 14px。切换目的地回到工作区顶部，关闭详情恢复列表位置。

预设保留草稿、效果图、版本及显式上架/下架。用户列表来自服务端，展示来源、头像、昵称、用户 ID、状态、注册与最近登录；详情补充累计登录、最近更新及脱敏 QQ 标识。搜索、筛选、分页、加载、无用户、无匹配结果、读取失败和会话过期都有明确状态。启用及停用账号前确认，停用说明 App 登录会话会失效且资料保留，资料冲突要求重新读取。

用户已确认尚未申请 QQ 互联。后台只显示服务端接入状态与真实空态，不伪造已接入用户；管理员账号密码与 App 普通用户 QQ 登录分开。浏览器不接收 AppKey 或服务密钥。配置状态不代替真实 QQ 登录验收。

轻重通过语义表面、单一边界与间距建立，顶部栏和登录卡保持平面。系统无衬线正文 15px、页面标题 28px、蓝色当前目的地与统一线性图标延续云白石墨世界。一般按钮 42px、导航项 46px；手机和顶部局部操作按源码收紧。动效仅用于按钮反馈和抽屉状态；保留减少动效、3px 键盘焦点及浅深色。Web 有效 tokens 取后加载的 `styles.css`：浅色成功绿为 `#217A43`，占位文字为不透明次要色；不回写 Android tokens。

本地合成桌面 / 手机视口批量检查及一次修复确认后，独立完成复核为 **SHIP，仅限已审阅的 Web UI**。截图使用 JPEG，保存在 `.impeccable/review/online-admin-2026-10-18/`；它们不是生产用户或真实手机登录证据。对比度与范围记录见 [完成复核](../../docs/design-review/admin-management-2026-10-18.md)。新版线上部署、真实 QQ / Android 新登录及真实手机尚未在此记录中验收。

## 1.4.0 · 社区与 App 版本扩展（2026-10-18）

以上两项菜单及旧验收结论保留原时间范围。当前侧栏增加“社区管理”“App 版本”，桌面继续左任务、右内容；760px 及以下四项文字导航可横向滚动，隐藏图标。所有合法、启用的后台管理员可管理 App 版本，不以固定用户名限制权限。

“社区管理”分为投稿审核、评论管理、举报处理、风控规则、操作审计。投稿详情展示最新内容、私有文件、历史修订和处理说明，提供通过、退回修改和下架；版本冲突要求刷新。注册未满 24 小时且没有可见评论的账号先送审，待审评论提供“通过审核／不予展示”（对应 restore／hide），回复获批后在事务内发通知。既有评论可隐藏／恢复，举报可确认违规／忽略；两者为独立处理。点击作者或输入用户 ID 可设置禁言及禁止投稿期限，留空可解除；禁言只限制发表评论，保留读消息及删除自己内容。规则保存展示成功文字，审计记录实际前后值。每日社区额度按 UTC 计，规则默认值及注册的安装／来源／全局原子限额见 [社区与更新说明](../../docs/community-and-updates.md)。

社区列表保留 14px 圆角、正文换行与长文本折行；详情使用 18px 圆角，桌面最大宽 680px，700px 及以下收紧留白并重排。规则表单双列在 700px 及以下改为单列；五项栏目可横向滚动。一般可操作项至少 44px 高，保留 3px 键盘焦点和既有浅深色语义。

“App 版本”使用 20px 圆角上传面板和版本列表、24px 圆角详情对话框。上传实际签名 APK、选择正式或测试渠道并填写更新说明；服务端读取包名、版本、最低 Android、哈希和现有固定证书，最大 4 MiB、分块 512 KiB。校验后为草稿，上架需要二次确认，撤回阻止新下载；包及已发布元数据不可覆盖。详情保留真实状态、可折行的校验信息及审计，提供公开下载页入口。当前实际上传存储预算为全环境 UTC 每日 64 MiB，变更请求每 15 分钟 256 次，分块与合成后的完整文件均按实际写入字节扣额。

公网 `/preset-library/download/` 无需登录，显示版本、渠道、最低 Android、大小、更新说明、校验信息及下载页二维码；缺正式版时明确标测试版，撤回不静默回退旧版。三张原生预览来自 `community-native/final/light/` 的 QA 截图，明确标注“演示数据”，无私有用户数据或凭据。当前使用 CloudBase 测试域名，首次浏览器访问可能出现平台访问确认；正式商业域名尚未配置，需要用户自有域名。此公开入口与后台管理会话分开。Android “检查更新”保留用户选择下载与系统确认安装，直播／导入／传输／保存／处理期间阻安装，空闲连接另行确认断开。

## 管理员修改密码（2026-10-21）

右上角“修改密码”仅在登录后显示，对话框提供当前密码、新密码和确认新密码。新密码沿用 16–256 字符策略，原样保留空格和符号；相同密码及两次输入不一致会阻止提交，当前密码错误保留登录状态并显示错误。保存时禁用表单操作，防止重复提交及取消；空闲时 Escape 或取消关闭并清空敏感字段。成功后撤销该管理员全部会话并返回登录页，预填账号并持续显示成功提示。

对话框最大宽 460px、圆角 16px，沿用现有浅深色语义颜色，保存与取消按钮至少 44px 高。480px 及以下已登录顶部栏隐藏品牌文字，为外观、修改密码及退出操作留出空间；既有视觉世界保持继承。

独立 UI 复核为 **SHIP，仅限本轮五张截图**：[桌面表单](../../docs/validation/admin-password-20261021/desktop.png)、[当前密码错误](../../docs/validation/admin-password-20261021/desktop-error.png)、[390px 手机浅色](../../docs/validation/admin-password-20261021/mobile-light.png)、[320px 手机深色](../../docs/validation/admin-password-20261021/mobile-dark.png)及[深色手机成功状态](../../docs/validation/admin-password-20261021/success-mobile-dark.png)。已审阅的文字与操作颜色组合对比度为 5.39:1–15.57:1，无实质问题。静态检测使用正则降级模式，结果为 `[]`；不据此声称完成全选择器或完整对比度检查。

149 项服务测试、34 项隔离 PostgreSQL 检查和最终 63 个模块语法／源码检查通过。五张截图及浏览器交互验证来自本地隔离的无界面 Edge、MemoryStore 与合成账号。用户明确批准后，已执行生产迁移并仅发布六个相关运行文件；13:47:18（北京时间）云函数恢复 Active，13:54:23 完成独立线上 11 项验收，临时管理员、会话及尝试记录均已清理。截图仍只证明原本地界面范围，生产接口证据另列于[验证记录](../../docs/validation/admin-password-20261021/README.md)，不扩大既有历史验收范围。

### 密码长度追加调整（2026-10-21）

按用户要求将管理员新密码最短长度从 16 改为 **8 个字符**，不要求字符组合。新密码与确认框统一 `minlength=8`，辅助文字改为“至少 8 个字符，无需特定字符组合。”；服务端及哈希函数同样接受 8 位纯数字，7 位仍拒绝。现有布局、配色和改密后的重新登录流程沿用。150 项服务测试、63 模块语法检查及本地浏览器 8 位纯数字改密和登录通过；14:01:45 已仅发布三处相关运行文件。新证据见[8 位密码验证](../../docs/validation/admin-password-8-20261021/README.md)，原截图保留首轮 16 位要求的历史范围。
