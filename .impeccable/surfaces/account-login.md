# Huevia 账号入口

用户在 2026-10-18 审核并选择“轻简入口”。0.9.10-beta 将该方案实现为 Android 原生 Views，使用 UiPalette 的云白、石墨和蓝色角色。

首屏居中显示选定的 Huevia 图标、名称与“把喜欢的色彩，带进相机”，以 QQ 快捷登录为唯一填充主操作。账号密码按需切换，注册为文字入口。顶部游客使用直接关闭账号页；空闲密码子页返回收起表单，忙碌时返回仍可退出账号页。短窗口改用横向紧凑品牌区，内容通过原生 ScrollView 保持可达。

主按钮最小高度 52dp、圆角 18dp，使用 RippleDrawable，移除默认抬升阴影。文字与显隐操作至少 48dp 触区。输入框使用 card、outline 与 focused primary 边框，圆角 14dp；文本 16sp、标签 13sp，密码显隐位于输入框内。账号规则只在注册页和输入校验时出现。处理中禁用并淡化方式切换及注册入口，保留游客与系统返回。

底部保留本机内容可在游客模式使用的说明、QQ 隐私说明和登录帮助。窄于 350dp 或字体倍率至少 1.3 时，底部链接改为纵向，避免截断。登录帮助解释相机 Wi-Fi 与联网条件。

QQ 明确同意、独立账号、授权生命周期与会话保存逻辑沿用既有实现。密码不进入持久化存储，切换方式、离开账号页和进入后台清理密码；用户名仅作为本轮操作的草稿。验收记录见 dist/nikon-usb-0.9.10-beta-VALIDATION.txt。
