# Direction contract

MODE: Operate. Photo editing is a scoped addition to Huevia's approved native Android visual system.

THESIS: A camera preview opens as a full-screen browser; a photo with a completed local JPEG original opens the editor, with online filters by default, a separate “我的” source, strength, and explicit export. Match the user's approved PixelCake-inspired composition and requested Apple-style glass while retaining Huevia's blue.

FIRST VIEWPORT: Without a completed local JPEG original, use the pure full-screen browser, favorite control, bottom export, and preview-failure reason/retry; no filter dock, strength, editor binding or online preset request. With a completed local original, use the fixed graphite editor canvas, filename/position/back and blue export in the top bar, contained uncropped photo, original comparison, star and version tools above the compact bottom dock. “在线 / 我的”, fixed-height source status, category chips, current-photo filter thumbnails, strength and editing note belong only to this eligible editor. Landscape moves the editor dock right and permits vertical scrolling.

ENTRY RULE: Eligibility depends on the completed local JPEG original, not the current tab, camera/local/live source, or an already-rendered filter export. Completed camera download or live save triggers viewer-status re-evaluation and rendering. Switching to a preview-only photo unbinds the prior editor to reject old-photo work. The visible comparison label is “原图”; press-and-hold behavior and accessibility action descriptions remain.

INTERACTION: Filter and strength changes remain previews and account-scoped per-photo drafts until explicit export. Online catalog loading uses an independent worker; visible/selected filters lazily read the real SHA/length/container-verified recipe without importing it into “我的” or replacing same-SHA local metadata. Category order is 人像, 风景, 胶片, 黑白, 日常, 夜景, followed by actual custom and uncategorized values. Source changes clear category/search and reset position without restoring the old source's scroll. Network failures explicitly show validated same-service cache or a retryable error. “全部” opens a roughly 72% portrait / 90% landscape bottom sheet with source/category controls, search and three columns. Export confirms current effect, strength, JPG and original dimensions; batch export retains each photo's independently frozen settings. Never add AI, beauty, crop or manual color panels in this scope.

FORM: Native Java Views; system typography in sp; 48dp controls; surface #22252A, field #30353D, text #F4F5F7, secondary #ADB6C3, accent #8DBBFF. Glass uses a real preblurred 64px sample of the current photo, dark backing, fine edge and top highlight, with a 26dp outer radius. Collapsed cards are 84×110dp with 78dp images and 26dp labels; source status stays 28dp and the editing note stays 24dp, with single-line ellipsis and full tooltips. Source buttons stay single-line at font scale 1.3. Landscape picker puts sources in the title row and combines search and horizontally scrollable categories in one 48dp row to preserve complete image/label rows. Main photo preserves aspect; only thumbnails crop. No decorative raster or new photo asset ships.

SELECTION STYLE (71): “在线 / 我的” shares a 32dp visual-height rail with a neutral 28dp selected plate and 48dp touch bounds; leave 12dp before “全部”. Categories use blue text and an 18×2dp underline instead of large capsules, with 6dp header/category spacing, 6dp chip gaps and fixed 13sp medium weight to avoid width changes. The popup uses the same style and reuses children while its category set stays unchanged. The 70 completed-local-original eligibility and “原图” label remain.

ALBUM / EXPORT (72): Top export has a 64×36dp visual background inside a 64×48dp touch target, with single-line 13sp text. Downloaded albums replace the refresh button with pull-to-refresh at the list top. Camera pagination shows a bottom loading spinner, failure/retry or end status only while loading or at the list end; successful pages append into the same grid. Compact landscape anchors the full 48dp footer at bottom/end (136dp wide, 12dp end / 8dp bottom), while normal height centers it above navigation. The 70/71 editing and selection rules remain.
