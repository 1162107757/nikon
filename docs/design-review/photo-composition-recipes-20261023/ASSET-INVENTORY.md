# 构图与我的配方 · 素材清单

日期：2026-10-23。范围：在既有 Huevia 原生照片编辑器中增加裁剪、旋转、拉直及保存／复用“我的配方”。沿用已实现的平面深色编辑器与浅蓝强调；本轮不建立新的视觉方向。

**新增生产栅格素材：0。** 新增五个控制图标均由现有 `AppIcon` Canvas 图标族绘制；照片、预览与缩略图继续来自用户本地原图及运行时处理。

素材溯源：五个图标是本轮直接在项目代码中编写的简单几何控制符号；其可编辑来源即 `AppIcon.java`，没有生成图、外部下载或授权不明文件。既有设计依据为 `DESIGN.md` 中当前平面照片编辑器与统一图标族记录，以及 `docs/design-review/photo-basic-adjustments-20261022/ASSET-INVENTORY.md`；既有 AI 合成模板仅延续原用途，不是本轮新增素材或真实相机样张。没有需要嵌入生成提示词的新栅格文件，也没有待生产素材。
