# 照片直播布局评审原型

本目录是以 HTML/CSS/JavaScript 实现的浏览器原型，供用户比较并选择布局。当前没有选定最终方案；“选这套方案”只在本页标记偏好，仍需在聊天中确认。根目录设计约定保持不变，原型未修改 Android 页面、运行时、版本或 APK。

## 已实现的结构

三套方案共享相册标题、连接状态、相册分类、项目入口、当前原图状态及底部导航。A「照片优先」采用项目 / 预设 → 传输区 → 最新大图 → 三列缩略图；B「项目工作台」采用项目资料与保存 / 队列数量 → 传输区 → 三列纵向照片；C「沉浸影棚」采用大画布、画布内传输浮层及横向胶片条，通过“全部照片”进入整理示意。

`mount()` 一次建立三个预览，`update()` 只改状态类、文字、进度及空态可见性。传输区最终高度为 76px，重试与停止共用操作位置；空项目保留照片槽位。模拟使用同一组示意图片，不实际接收、落盘或插入新照片。

项目与预设选择、详情、接收记录、照片放大与箭头切换、星标筛选、选择及套用预设均有示意交互。未完成的当前照片不能进入批处理选择；停止保留项目与已保存照片；预设更改只表达影响后续照片、效果另存及原图保留。C 的全部照片弹层展示放大和星标筛选，正式版完整整理能力仍待原生实现。

## 状态与进度

11 种状态使用同一传输槽位：

| 状态 | 显示及操作 |
| --- | --- |
| `receiving` | 当前原图百分比、已收 / 总字节，停止 |
| `waiting` | 等待拍摄、已保存数量，停止 |
| `preparing` | 准备中，取消 |
| `unknown` | 接收中、大小未知，不显示虚构百分比，停止 |
| `saving` | 接收完成、保存中，停止 |
| `processing` | 原图已保存、预设处理中，停止 |
| `saved` | 已保存到相册，停止 |
| `error` | 单张待重试，保留上一张照片，重试 |
| `disconnected` | 连接中断，保留已保存照片，去连接 |
| `stopped` | 已停止、保留项目，继续 |
| `idle` | 空项目、固定空态，开始 |

百分比属于当前 JPEG 原图，正式版应取 `receivedBytes / totalBytes`；本页的 68%、18.2 MB、文件名和队列均为模拟数据。接收达到 100% 后仍显示保存阶段，只有原图成功落盘并发布到相册后才称“已保存”。原图保存与预设效果生成分别表达。模拟保存计数按当前文件只增加一次，进入后续等待阶段不再重置为初始 12 张。

## 视觉、适配与素材

`index.html` 先加载 `assets/apple-tokens.css`，再加载 `review.css`。共享文件提供 Apple 风格基础与偏好回退；本原型实际颜色、尺寸和动效主要由后者的 `--review-*`、`--app-*`、`--glass`、`--motion` 及组件规则决定，并未全面引用共享语义 token。采用系统字体栈、云白 / 石墨底色、蓝色操作、细线 SVG 图标；玻璃材料集中在浮动导航及照片上的控件，C 的状态浮层始终使用深色局部配色。

默认浅色，主题按钮显式切换整个页面和三个预览。桌面并排显示；900px 以下隐藏“并排比较”，默认显示 A，可逐一切换 B / C；540px 以下缩小外框和标题，规则说明改为单列，手机预览内部滚动。主要应用控件保留 44px 高度，包括分类、预设、传输操作及关闭按钮；这不是全页所有控件均为 44×44px 的声明，移动端主题按钮和批处理条按钮仍为 40px。已有键盘焦点、状态播报、减少动效 / 透明度及增强对比度规则。

`photo-atlas.png` 复用 2026-10-16 由 OpenAI image generation 生成的六格概念照片，以 SVG 裁切复用，不能代表真实 Nikon NCP 或预设效果。完整提示词保存在同名 JSON 及 PNG 元数据，来源见 [assets/provenance.md](assets/provenance.md)。`huevia.png` 直接复制用户指定的既有图标，未重绘或改像素，来源与哈希见 `assets/huevia.png.json`。

## 评审证据与后续边界

已核对 `.impeccable/review/photo-live-redesign/` 中的 `comparison.png`、`mobile-a.png`、`mobile-b.png`、`mobile-c-dark.png`。`state-layout.json` 记录三个方案在 11 种状态下的传输区、大图及照片列表几何变化为 0px。新鲜评审结论为 `SHIP_WITH_NOTES`；其中模拟已保存数量重置的问题已在 JavaScript 修正并复核。这些截图和测量只证明浏览器原型的结构与状态表达，不能证明 Android 真机闪动或后台传输已修复。

用户确认方案后，原生实施仍需先处理无变化通知及整页重建链，再稳定主图尺寸、图片绑定与局部状态更新，并接入真实字节和保存阶段。保留应用级 runtime、串行 PTP 队列、前台服务及后台连接，不以重连刷新页面。需另行验证原生视图更新、已显示图片保留 / 保存后替换、未知总量、失败重试以及前后台切换。
