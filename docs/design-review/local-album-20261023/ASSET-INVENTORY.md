# 素材与视觉边界

本轮不新增生产栅格或商业素材。相册网格使用用户授权的真实手机照片或正式 App 内照片，界面沿用 UiPalette、系统字体、Canvas AppIcon 与原照片优先编辑器。新增导航复用现有同步／照片图标，不引入新图标家族。

验证图片来自既有应用模板与清楚标记的合成 JPEG／透明 PNG；不会上传到用户云端或生产图库。原生截图保留原始图并在复核副本记录原始路径、状态、APK 身份及来源，非生成设计稿。

权限与系统选图参照 Android 官方文档：
- https://developer.android.com/about/versions/14/changes/partial-photo-video-access
- https://developer.android.com/training/data-storage/shared/documents-files

本轮为已批准现有视觉体系的代码扩展，不另行生成组合稿；需求、真实原生界面和最终独立完成复核共同约束交付。
