# 本地相册、同步与保存位置 · 已批准需求

用户在 2026-10-23 审核并批准合并需求，随后明确“可以，开始实现”。现有根相册改名同步，保留相机照片、照片直播、已下载与旧数据；新增根相册，提供手机照片和 App 内照片两个来源。授权范围内的手机 JPG/JPEG、PNG 和真实 App 原图／版本进入既有照片优先编辑器，复用滤镜、13 项调节、构图、配方、对比、撤销和草稿；支持单张及多选批量处理，保留源照片。

相机单张／批量保存及直播首次默认仅 App 内，编辑成品导出默认手机相册；各场景分别记忆明确选择，直播按项目记忆，任务及失败重试冻结选择。App 内仅正式保存、不写系统相册、不自动上传；用户可之后明确另存手机相册。同照片同版本已有效发布时不再重复生成，额外副本须明确勾选另存；新副本按本次时间。旧公有照片不自动删除，缓存清理不删除正式原图或草稿。

相册切页不主动断开相机或停止直播；冲突任务说明等待，已接收原图和任务保留。授权拒绝／部分照片／撤销、空列表、原图缺失、存储失败均有可恢复状态。仅浏览不全库复制，缩略图和列表按需加载。PNG 保留源文件，JPG 输出需明确白底转换，不静默修改系统原图。示例验收：直播20张选仅App内→系统新增0；处理3张并保存→新增3；重复保存相同3版本→仍3；明确另存才新增。

视觉沿用 UiPalette 云白／石墨、Canvas 图标、48dp 触区和既有紧凑编辑器；这是功能扩展，未要求新视觉世界或新组合稿。代码和真实原生截图为交付证据。测试使用隔离模拟器和清楚标记的离线夹具，不能替代实体相机／图库权限真机验证。用户此前授权完成后直接上传测试版，继续沿用，发布成功以实际回执为准。

实现中追加确认：用户要求用悬浮“＋”按钮选择照片；手机照片未授权时，中间直接显示可点击的“点击获取授权”。据此收起常驻操作行，刷新／多选等操作进入菜单，保留两种照片来源，让照片主体占用更多空间；横屏须显示完整、可辨认的照片行与文件名，授权引导也可见，触区保持至少 48dp。
