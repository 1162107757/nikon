# 0.9.7 预设列表与分类复核

采用现有云白 / 石墨 / 蓝色，预设首页改为原生双列卡片，竖幅封面、15sp 名称、分类与紧凑下载动作。卡片 16dp 圆角、列间距 12dp、行间距 14dp；类别使用横向筛选，当前选项以操作色与浅色背景标识。来源切换、连接状态和浮动底栏沿用原有语义。

列表使用 GridView 而非一次创建全部预设；每个来源 / 分类保存原生滚动状态。详情继续提供原图对比、曲线、下载或导入，本地新增分类入口。分类主数据随预设保存，不通过图片名称猜测，不改变原 NCP。

本轮最终包的 `feed-light.png`、`filter-light.png`、`feed-dark-large.png` 位于 `.impeccable/review/preset-feed-0.9.7/`。八条目录与封面变化仅为内存测试内容，未发布到云端。`filter-light.png` 是探针恢复“全部”后的画面，实际胶片筛选 / 详情返回 / 未分类检查以同目录的运行日志为证。本地持久化筛选另有 `local-category-filter.png`。

独立只读复核结论为 **SHIP，仅限已提供的手机竖屏浅色 / 深色大字截图及所读源码**。未发现材料级遮挡、溢出、对比度、标记或新增内存问题。分类和下载有独立描述，底部 108dp 滚动留白允许最后一项完全露出；图片两线程和既有 16MiB 缓存保留。

没有宣称横屏 / 平板、极大字体、TalkBack 真机或性能认证。真实手机证据仅限覆盖安装与启动；相机及照片直播行为不属于本轮验收。完整数据、云端、部署与清理证据见 [交付记录](../../dist/nikon-usb-0.9.7-beta-VALIDATION.txt)。
