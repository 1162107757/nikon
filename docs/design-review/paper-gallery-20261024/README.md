## 怎么看

原型用了相对路径引用生产模板原图，需经 HTTP 打开（直接双击 `index.html` 也能看，
但部分浏览器会拦截本地文件的相对上级路径）。在仓库根目录起一个静态服务：

```bash
node .tooling/design-preview/server.mjs .
```

然后访问 `http://localhost:4173/docs/design-review/paper-gallery-20261024/`。
