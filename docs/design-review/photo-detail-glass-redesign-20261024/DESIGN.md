# 照片细节 / 直方图 · 玻璃浮层重设计 v2

日期：2026-10-24。状态：**设计稿，待审核。本轮只出设计，未修改 `app/` 任何源码、未构建、未安装、未验证。**

原型：
- [prototype.html](prototype.html) —— 编辑页 / 细节页 / 直方图浮层（5 屏，可点击）
- [prototype-export.html](prototype-export.html) —— 导出设置 / 批量进度 / 结果汇总 / 异常态（6 屏，可点击）

两份都是单文件自包含，顶部有「标准 ↔ 1.3 倍字号」开关。

## 1. 为什么重做

91 轮的正式稿 [review-editor-v1.png](../photo-detail-export-histogram-20261024/review-editor-v1.png) 在真机跑出来后被否定了两处：

1. 细节页底部那块占画面高度的大黑底工具面板 —— 照片被挤小。
2. 直方图页头「亮度 / RGB / 预览统计 / 暗部 / 高光」连成一整条选中块 —— 读不出哪个是当前项。

随后的几轮是在原结构上打补丁（挪线、改 padding、关 outline clip），模式下划线到 `5e9688ba…` 仍未在真实 framebuffer 上可见。本稿不再补丁，直接换结构。

## 2. 三条设计原则

| 原则 | 落地 |
| --- | --- |
| 照片拿走全部可用高度 | 细节页取消底部工具面板，画布用完整安全区；顶部操作覆盖在画布上 |
| 控件退到照片边缘内侧 | 所有控件是锚定照片边缘 12dp 的紧凑玻璃浮层，不是通栏面板，照片不因控件开合而位移 |
| 选中态靠结构区分，不靠大色块 | 模式 = 文字 + 2dp 下划线；开关 = 独立 28dp chip；只有真正的单选分段（缩放、比较）才用填充选中 |

## 3. 部件规格

单位 dp / sp。

### 3.1 共享玻璃材料 `PhotoGlassDrawable`（沿用）

从照片 View 局部 `source.draw()` 采样，采样图最长边 ≤192px，box blur；约 65% 深色 tint + 35% 图色透出，加 1px 细边。照片变换或内容更新时 `refreshGlass()`。采样只作控件材料，**不进入真实像素、直方图输入、草稿或导出数据**。

### 3.2 细节入口（编辑页，照片左下）

- 视觉高 **32dp**，触达高 **48dp**，内容宽约 **91dp**；18dp 放大镜 + 12sp「查看细节」。
- 距照片左 / 下各 12dp，随照片实际边缘锚定。
- 改动点：从白底白图标改为深色玻璃；文字前不留空白，整块一起点。

### 3.3 直方图浮层（编辑页，照片上）

- 常规 **280×104dp**，圆角 18，距边 12dp。
- 1.3 字号时外层宽度弹到约 **316dp**，上限 **328dp**，并受实际可用宽度约束 —— 避免警示百分比截断。
- **位置**：照片上方有足够留白时优先占留白（避开人物主体）；留白不足才锚到照片上缘右侧。横屏改走右上。
- 行结构：`亮度 | RGB | ——弹性—— | [暗部] [高光]`，行高 28dp，触达 48dp。
- 模式：文字 + 文字下方 2dp 短下划线。下划线画在 Inset face **内部**，关闭平台 theme tint 与 outline clip；设置背景后显式清零内容 padding 并居中，页头行关闭 baseline alignment。
- 警示：两个独立 28dp chip，中间 6dp 间隔。高光暖色斜纹、暗部蓝色斜纹，**图案 + 文字双重编码**，不只靠颜色。
- 图表：256 bins、x 轴固定 0–255、纵轴按该快照最大计数归一化、RGB 三线共用纵轴。角标常驻「预览统计 · 8 位 sRGB」。

### 3.4 细节页浮层

| 浮层 | 位置 | 规格 |
| --- | --- | --- |
| 顶部 header | 覆盖画布，渐变底 | 52dp 高，返回 48dp 触达，标题两行（状态 + 文件名） |
| 比较胶囊 | 顶部居中，header 下 | **216dp × 40dp**，两段「当前效果 / 调色前」 |
| 尺寸 / 倍率 tag | 照片右上 | 独立玻璃 tag，26dp 高，**11sp 单行**，避开 header 与胶囊 |
| 缩放浮层 | 照片左下 | **232×55dp**（1.3 字号 → 268dp），仅「适应 / 100% / 200%」，选中视觉 32dp、触达 48dp |
| 定位小窗 | 照片右下 | 76×98dp，底部抬至 76dp 以避让缩放浮层；仅放大时出现 |
| 说明行 | 底部居中 | 10.5sp 两行，渐变底，不拦截触摸 |

改动点：**尺寸 / 倍率从左下控件里拆出来**，不再和缩放按钮共占一块面板。

### 3.5 状态分支

| 情况 | 标题 | 说明行 | 调色前 |
| --- | --- | --- | --- |
| 可恢复当前编辑 | 细节预览 | 同构图对比 · 不含边框 | 可用 |
| 缺可信参数 / 关联的历史 JPEG | 已保存版本 | 查看完整文件像素 · 含已烘焙边框 | 禁用，说明「此版本暂无法恢复调色前内容」 |

禁用态保留文字原因而非只变灰，可被辅助功能读出；**不出现「不含边框」承诺，也不推测剥框**。

## 4. 导出 / 批量 / 结果页

信息顺序沿用需求 5.1：照片与数量摘要 → 三档 → 实际尺寸与质量 → 保存位置 → 保存方式与已有状态 → 预估体积与原图保护 → 主操作。改的是密度与状态表达：

| 部件 | 规格 | 改动 |
| --- | --- | --- |
| 页面骨架 | 内容区自己滚动 + 底部操作吸底 | **改**：v1 整页流式，1.3 字号下底部按钮会压住预估体积与行内错误 |
| 规格数字 | 24sp 粗体 + 11.5sp 副说明 | **改**：从巨号降级，省出的高度给「保存方式」与体积状态 |
| 内容 / 导出尺寸 | 可展开，仅有边框时出现 | 留：输入口径一律是最终含框成品画布 |
| 自定义输入 | 数字输入框 + 质量滑块，行内错误在输入框正下方 | **改**：错误不走吐司，主操作同步禁用 |
| 保存方式 | 独立分组：已有状态说明 + 「另存新副本」勾选 | **改**：v1 混在「保存到」一行；已有 / 被删 / 不可核对三态各有自己的文案与动作 |
| 预估体积 | 范围 / 估算中 / 实际 / 不可用 四态 | 留：估算不可用不阻止导出 |
| 原始文件入口 | 主按钮下方低强调文字 + 确认弹窗 | 留：确认文案写明不应用当前调色、不使用上方尺寸质量设置 |
| 批量进度 | 阶段状态 + 已完成张数 + 逐张行 | **改**：取消时先写「正在取消，等待当前步骤结束」 |
| 结果汇总 | 新保存 / 复用 / 失败 / 未处理 四类计数 + 逐项原因 | **改**：v1 没有结果页，这里补上 |

## 5. 不变的部分

[REQUIREMENTS.md](../photo-detail-export-histogram-20261024/REQUIREMENTS.md) 的技术范围全部保留，本稿只覆盖其中细节页与直方图的视觉与布局约束：

- 100% = 内容像素对应屏幕物理像素的定义、瓦片 halo 与空间半径规则；
- 直方图统计对象（完整构图内容、排除边框 / 留白 / Logo / UI / 警示叠层）、亮度公式、警示命中条件与百分比规则；
- 警示不进入导出、不进入草稿、不进入撤销；
- 三档导出、保存位置、去重与原图保护规则（本稿未改导出面板）。

主 Tabbar、暖白 / 石墨 / 桃色体系、五个编辑分组入口均不动。

## 6. 审核时想确认的点

1. 直方图默认落在照片上方留白是否符合预期；留白不足时锚到上缘右侧是否可接受。
2. 尺寸 / 倍率独立成右上 tag，是否比原来挤在左下更好读。
3. 模式用下划线、开关用 chip 的区分强度够不够 —— 这是上一轮反复没解决的点，想在稿子上先定死。
4. 细节页取消底部面板后，操作是否还够明确（适应 / 100% / 200% 只剩左下一处）。

## 7. 边界

原型中的照片、文件名、参数、直方图形状与百分比均为示意绘制，**不是实测值**，也不是 App 已实现截图。玻璃效果在原型里用 `backdrop-filter` 近似，与原生 `PhotoGlassDrawable` 的采样模糊不是同一实现，最终可见性仍须在真实 framebuffer 上确认。
