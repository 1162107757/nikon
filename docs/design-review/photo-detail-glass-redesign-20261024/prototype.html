照片编辑器 · 完整原型

第一台手机是编辑器主体，底部五个分组都能点：滤镜、调节、构图、边框、配方。 画布、缩放与照片位置在滤镜 / 调节 / 配方之间共用，构图按需打开独立全屏工作区。 工具区固定 224dp（176dp 面板 + 48dp 入口行），所以切分组时照片不会跳动。 后面几台是全屏态：构图工作区、完整滤镜选择框、细节页、横屏。

设计稿 v2 · 待审核
字号 1.3 倍下：参数条与滤镜条横向滚动、直方图 280→316dp、缩放浮层 232→268dp，均不截断。
1 · 编辑器主体 · 五个分组可切换 默认停在「滤镜」。点底部切分组，点顶部图标开直方图，点左下进细节页。

滤镜头行 48dp：最左 GRID 四宫格、在线 / 我的、短状态、可横滑分类。 卡片 66×80dp（52dp 图 + 22dp 名）。调节是撤销 / 重做 + 一根滑杆 + 横向 13 项参数条， 已改项带点标记。

2 · 构图 · 全屏暂存工作区 可切比例、拖拉直滑杆、点旋转 90°；取消 / 应用在顶部。

四角手柄 + 三分网格。比例依次为原比例、自由、1:1、4:3、3:2、9:16； 拉直 −45.0° ~ +45.0°、步长 0.1°，自动放大覆盖避免黑角。 取消或 Back 不改草稿，应用后整个构图只记一次撤销。

3 · 完整滤镜选择框 从 GRID 打开。三列网格、搜索、分类与来源共用同一套选择状态。

分类与横条共用选择处理，同步两处分类、真实计数并重置结果位置。 标题显示来源、所选分类与实际数量；读取失败为 ERROR 可重试，不支持为 UNSUPPORTED 并禁选。

4 · 细节页 · 可恢复编辑 整屏画布，无底部面板。点 100% / 200% 看定位小窗出现。

尺寸 / 倍率拆成右上独立 tag（11sp 单行），不和左下缩放浮层挤在一块面板里。 定位小窗在右下、抬高到 76dp 以避让缩放浮层。

5 · 细节页 · 已保存版本 缺可信参数关联的历史 JPEG：标题与说明改写，「调色前」禁用。

标题为「已保存版本」，说明改成「查看完整文件像素」，不出现「不含边框」承诺。 禁用态保留文字原因而不是只变灰。

6 · 横屏编辑器 工具移到右侧 300dp 区并可纵向滚动；短状态隐藏，完整状态留在选择框。

横屏右栏合并来源与分类行，保留完整缩略图和标签。 直方图改锚右上，避开左下控件；宿主不对已分配的剩余高度二次扣减。

分组面板内容约束
工具区骨架224dp = 176dp 面板 + 48dp 入口行 + 1dp 分隔 留 五个分组共用固定高度，切换时照片不位移；不再常驻大圆角玻璃包围或重复状态页脚。
滤镜48dp 头行（GRID / 来源 / 短状态 / 横滑分类）+ 66×80dp 卡片条 + 强度 留 强度 0–100% 只影响滤镜；「无滤镜」禁用强度但保留手动值。卡片按身份保留，异步缩略图原位更新、保持 scrollX。
调节撤销 / 重做 + 一根滑杆 + 可点数值 + 横向 13 项参数条 留 顺序为亮度、曝光、对比度、高光、阴影、白色、黑色、色温、色调、饱和度、自然饱和度、清晰度、锐化；首次为曝光。曝光 −3.0~+3.0EV 步长 0.1，锐化 0–100，其余 −100~+100。
构图面板内只放当前状态 + 「打开构图」+ 重置 改 不在 176dp 里塞裁剪控件；真正操作进全屏暂存工作区，避免小面板里拖四角。
边框四种样式卡 + 可滚动信息行 留 无边框 / 模糊居中 / 模糊侧栏 / 白底信息；EXIF 自动读取，可搜索机型、自定义、补填或隐藏。手填只改展示，不改原始字节。
配方标题行 + 单行「保存当前」+ 可滚动列表 + 说明 留 只保存滤镜、强度与 13 项手动值，不保存构图；套用时保留目标照片构图，记一次可撤销编辑。本机按账号隔离，每账号上限 100 份。
撤销 / 重做当前照片会话最多 32 步 留 覆盖滤镜、强度、手动值、应用构图、套用配方与重置；一次连续拖动只记一步，无操作不产生草稿。
