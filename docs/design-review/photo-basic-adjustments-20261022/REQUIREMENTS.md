# 基础照片调整需求与实施记录

日期：2026-10-22　版本：2　状态：用户已批准，已实施于 80 / 0.14.0-beta（照片优先、紧凑双模式工具区）

在 Huevia 现有照片编辑器中增加基础调整，让用户在选择滤镜后，继续修正明暗、冷暖和色彩，也能直接调整无滤镜的原图。本轮提供 13 项参数，沿用每张照片独立草稿、明确导出及逐张设置批量导出的流程。

## 使用范围

面向相机照片下载完成后的快速修图，以及已下载照片和直播项目中的后期编辑。已有完整本地 JPEG 原图即可使用，基础调整可离线完成。

在线滤镜目录加载失败不阻断无滤镜的基础调整。已经选择但无法读取的配方仍须明确报错，不能偷偷跳过滤镜后按成功导出。

沿用现有暗色大图、蓝色强调和横屏右侧面板，按用户提供的醒图参考压缩常驻工具区。首次进入仍打开现有滤镜工具；增加平级的“调节”入口。原图、已保存版本及原有相机接收流程保持可用。

用户以“开始实现，我睡觉去了”批准本需求及[第二版界面设计图](design-board-v2.png)，并授权完成修正后发布测试版。80 / 0.14.0-beta 已完成原生实施；最终复核与发布结果由交付记录另行确认。首版因工具层级过多、照片不突出被退回，仅保留审核历史。

## 首版参数

参数按光线、色彩、细节归类，但界面不常驻分组标签，使用一条横向参数栏。默认全部为 0；曝光以 0.1 EV 为步长，其余参数以 1 为步长。范围为本轮实现值，不表示与其他软件的同名数值等价。

| 分组 | 参数 | 实现范围 | 用户能看到的作用 |
| --- | --- | --- | --- |
| 光线 | 曝光 | −3.0 至 +3.0 EV | 整体增减照片的明暗，用于明显欠曝或偏亮的画面；属于后期等效曝光补偿。 |
| 光线 | 亮度 | −100 至 +100 | 主要改变中间亮度，让主体更亮或更暗，尽量减轻对明暗两端的影响。 |
| 光线 | 对比度 | −100 至 +100 | 增强或减弱明暗反差；正值更鲜明，负值更柔和。 |
| 光线 | 高光 | −100 至 +100 | 单独调整较亮区域；负值压低亮部，正值提亮亮部。 |
| 光线 | 阴影 | −100 至 +100 | 单独调整较暗区域；正值提亮暗部，负值让暗部更深。 |
| 光线 | 白色 | −100 至 +100 | 调整最亮端的层次与白点感受，区别于范围更宽的高光调整。 |
| 光线 | 黑色 | −100 至 +100 | 调整最暗端；正值抬黑，负值加深黑位。 |
| 色彩 | 色温 | −100 至 +100 | 负值偏冷、偏蓝，正值偏暖、偏黄。JPEG 使用相对冷暖值，不显示为绝对开尔文温度。 |
| 色彩 | 色调 | −100 至 +100 | 负值偏绿，正值偏洋红，用于修正冷暖之外的偏色。 |
| 色彩 | 饱和度 | −100 至 +100 | 整体降低或增加色彩浓度；−100 为灰度效果。 |
| 色彩 | 自然饱和度 | −100 至 +100 | 正向优先增强原本较淡的颜色，减少对已浓艳颜色的继续增强；负向降低鲜艳程度。 |
| 细节 | 清晰度 | −100 至 +100 | 调节局部反差和纹理；正值更有质感，负值更柔和。 |
| 细节 | 锐化 | 0 至 100 | 增强边缘清楚程度；0 不增加额外锐化。 |

曝光与亮度应表现出可理解的差异，不能只是两个名称不同的相同滑杆。高光／白色、阴影／黑色分别作用于不同范围，参数帮助使用一两句话说明区别，用户可结合当前照片和原图对比判断。说明由 `PhotoAdjustments.Parameter.help()` 统一提供，可在更多菜单“参数说明”中打开，也可长按当前数值打开。

高光调整无法恢复 JPEG 中已经截成纯白的信息，阴影提亮可能显露原有噪点。清晰度和锐化以边缘自然为验收重点，避免明显光晕、色边和过度颗粒。

## 编辑入口与布局

编辑页以照片画布为主，底部在“滤镜”和“调节”之间切换，保留整张照片的全部设置。原生工具内容固定为 224dp 加 1dp 分隔（176dp 模式区及 48dp 底部模式选择）；主图使用其上剩余画布。最终 411×923dp 竖屏报告的底栏为 591px，照片画布在两个模式下边界完全相同。大字号保留可读文字和触摸目标；设计图的百分比只说明面积意图，真实照片完整比例与系统安全区优先。

在现有预设套用页上扩展，保留“在线／我的”、分类、预设缩略图及强度。把“在线／我的”、分类下拉与全部预设入口合并成一行，下方保留一条小缩略图栏和一根强度滑杆。分类与全部列表按需打开，不再额外常驻分类横条。

调节时，当前预设及强度只以画布顶部的小字显示，移除大预设卡片与常驻“更换”行；通过底部“滤镜”切回更换预设，保留手动参数。工具区采用贴底的平面黑色背景，去掉大圆角包围、拖动柄、重复状态与调整项数页脚。

```text
顶部：返回　小号文件名／位置　导出；星标与更多紧凑排布
画布：完整比例照片与缩放；小字显示预设／强度；角落放原图对比图标
滤镜工具：在线／我的＋分类下拉＋全部　→　小缩略图横条　→　强度滑杆
调节工具：撤销／重做＋一根滑杆＋当前数值　→　一条参数横栏
最底部：滤镜｜调节
更多菜单：版本、单项重置、重置调整、全部重置等非高频操作
```

一次展开一个参数滑杆，13 项参数在同一条横栏中滚动，按光线、色彩、细节顺序排列；不再叠加分组标签栏，也不同时展开多根滑杆。末尾露出下一项提示可横滑，当前数值显示在滑杆旁；已调整项有非颜色标记，辅助描述提供参数名、值和当前选择状态；修改状态另有可见点标记。单项重置可从顶部更多菜单进入，也可通过长按参数快捷归零。

滤镜与调节切换时使用相同的画布边界、缩放和照片位置，避免主体上下跳动。照片按原比例适应画布，横图允许上下留黑，不通过裁切或拉伸伪装更大的照片；双指缩放仍可查看局部。星标、版本和原图对比保留能力，但不再各自占据独立常驻工具行。

首次打开调整工具默认选择曝光；同一查看会话切照片时可保留正在使用的参数，但必须换成新照片自己的数值和预览。横屏沿用右侧面板，主图保持完整比例；大字号时参数区可滚动，导出和返回始终可操作。原生触摸目标至少 48dp，并适配系统返回、安全区和屏幕阅读器。

## 调节与恢复操作

| 操作 | 行为 |
| --- | --- |
| 拖动滑杆 | 数值立即变化，主图连续更新轻量预览；松手更新稳定预览并保存草稿。 |
| 点击数值 | 可输入精确值；超出范围或格式错误时提示，不覆盖最后有效值。 |
| 单项重置 | 仅把当前参数归零，其他参数和滤镜保留。 |
| 重置调整 | 一次清零全部基础参数，保留滤镜及滤镜强度；可撤销。 |
| 全部重置 | 清除滤镜与基础参数，回到原图起点；不删除历史版本，可撤销。 |
| 撤销和重做 | 覆盖滤镜、滤镜强度、基础参数与重置；一次连续拖动只记一步。当前编辑会话保留最多 32 步。 |
| 按住对比图标 | 临时显示最初的校验原图；松手恢复滤镜和全部调整。取消触摸、失焦时也正确恢复；提供“按住查看原图”的无障碍标签。 |
| 返回或切照片 | 保存该照片的草稿，不自动导出；重进恢复参数。撤销历史首版只要求在当前编辑会话中保留。 |

滤镜列表的中性项使用“无滤镜”：选择它仅取消滤镜，保留基础调整，滤镜强度禁用。照片工具中的“原图”仍表示按住查看最初原图，避免同名操作含义混淆。

## 滤镜与基础调整的关系

本轮采用固定处理顺序：

```text
校验后的原图
→ 所选滤镜及滤镜强度
→ 曝光与相对冷暖偏色调整
→ 亮度、对比度和明暗区域调整
→ 饱和度与自然饱和度
→ 清晰度与锐化
→ 当前预览或完整尺寸导出
```

用户的点击先后不改变这个顺序。每次从原图和完整设置重新生成，不在上次预览或已经压缩的效果图上继续累加。

滤镜强度只控制滤镜，不能连带缩小基础调整的强度。切换滤镜保留基础参数；无滤镜或滤镜强度为 0 时，基础调整仍然生效。基础参数全部为 0 时，保留既有滤镜效果；滤镜和基础调整均关闭时回到原图。

所有基础参数的中性值必须严格不增加处理。原有 NCP／NP3 文件不被修改，基础调整不写入相机，不改变直播项目的默认预设，也不自动作用到其他照片。

手动清晰度和锐化是对滤镜结果的额外调整。归零表示不额外处理，不会抹掉滤镜配方自身已有的清晰度或锐化效果。

## 草稿与版本

每张照片按当前账号和经过校验的原图身份保存独立草稿，包含不可变配方快照、全部基础参数和处理模型版本。v1 旧草稿的新参数按 0 读取，原有滤镜、强度和已导出状态兼容保留。中性基础参数继续使用既有模型身份；非零参数进入完整效果身份。

调节和自动保存草稿不生成永久效果图，不往系统相册增加照片。只有明确导出才创建或复用效果版本。导出完成后继续调节会形成新的待导出草稿，较早任务完成不能把后来设置标成已导出。

查看历史保存版本时沿用临时查看与恢复草稿规则。单项归零、全部基础参数已中性时“重置调节”、确认未变的精确值均为无操作；它们不生成草稿、不覆盖已保存显示版本，也不覆盖暂存的未导出草稿。编辑结果始终追溯校验原图，不能把已调过的 JPEG 再当原图叠加。无法确认来源时应提示原因。

快速拖动、切照片、切账号或退出页面时，旧异步结果不得覆盖新设置或新照片。相机只有预览图、尚无完整本地原图时，继续使用纯浏览布局；下载完成后重新判断编辑资格。

## 导出与批量处理

单张确认面板显示当前照片、滤镜和强度、基础调整项数、JPG 与原始像素尺寸。例如“某滤镜 70% · 调整 4 项”；无滤镜时显示“无滤镜 · 调整 4 项”。用户可展开查看非零参数，未修改的 0 值不逐项铺满面板。

导出沿用完整尺寸 JPEG、编码质量 95、sRGB 与既有捕获信息保留规则，另存为该原图的效果版本。所有参数在一次输出中完成，原图保持原字节。内存不足或写入失败时保留原图和草稿，明确提示，不能悄悄缩小导出尺寸。

批量导出继续按每张照片自己的设置执行：

1. 每张照片使用自己的滤镜、强度和基础参数；没有待导出草稿时沿用当前已保存版本的选择规则。
2. 开始时冻结每张照片的原图身份、配方和全部参数。之后继续编辑只影响下一次导出。
3. 最多一次 100 张，沿用取消、成功项保留与仅重试失败／未处理项。
4. 相同原图和完整设置重复导出可复用；任何一个参数不同，都不得误认成同一效果。
5. 批量和逐张导出使用相同处理规则，结果与尺寸应一致。

首版不增加“把当前调整复制给多张照片”。此功能可作为下一阶段的独立动作，避免与“每张照片各自设置的批量导出”混淆。

## 预览与画质要求

主图预览、当前照片的滤镜缩略图和完整尺寸导出使用相同的参数定义与固定处理顺序。滤镜缩略图应反映当前基础调整，不能选择时看到一种颜色、进入主图又变成另一种颜色。拖动时优先更新主图，缩略图在松手后按需刷新，不能阻塞调节。

轻量预览可以降低分辨率，最终文件必须保留原始尺寸。清晰度和锐化应针对预览／导出分辨率统一处理尺度，并用全尺寸局部对照检查，避免小预览自然而导出出现粗边、接缝或光晕。

调节过程不反复编码 JPEG，不因每次拖动累积色阶损失。本轮原生验证覆盖连续拖动、快速参数切换、切照片及独立批量快照等正确性。实体手机延迟、FPS 和长时间负载未验收，不以模拟器运行代替真机性能结论。

## 批准与实施核对

用户已确认 13 项参数及范围、先滤镜后基础调整、无滤镜与原图对比的区分，以及逐张设置批量导出。本轮不加入批量复制、裁剪或其他候选入口。参数条实现顺序为亮度、曝光、对比度、高光、阴影、白色、黑色、色温、色调、饱和度、自然饱和度、清晰度、锐化；首次选择参数为曝光，会话内切图可保留当前参数类型。
