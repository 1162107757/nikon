# 照片边框实施约定

用户提供三种成品参考、审核设计图并两次要求缩小机型栏文字和相机图标后，于 2026-10-24 明确“开始实现”。批准稿为 `border-templates-v3.png`；`camera-model-sheet-v1.png` 说明品牌／机型选择流程。此为现有 Android 编辑页的局部扩展，Operate 模式。

## 方向约定

照片与真实拍摄信息为主。沿用黑色画布、黑色 176dp 内容区＋48dp 工具导航和杏色选择态，增加第五个“边框”入口。样式页使用真实照片的四个缩略图、11sp 机型名称、9sp 状态和14dp相机图形，整行仍48dp。居中／侧栏分别用照片模糊铺底、圆角和软投影；白底信息条保留品牌、机型、Logo、参数和拍摄时间的分组关系。机型从原图读取，也可搜索、手选、自定义；文字和图形的尺寸修正属于明确批准约束。

## 实现与素材

`PhotoBorder` 保存独立不可变设置；`BorderPreviewProfile` 将边框加入缓存和导出身份。PED4 草稿迁移 PED1／2／3，旧草稿默认无边框。撤销／重做、切换滤镜、构图、单张配方和逐张批量导出均保留边框；批量“套用效果 → 照片边框”统一模板，各自读取原图信息。

`PhotoCaptureInfo` 只读原图。`PhotoBorderRenderer` 在色彩和定向构图后，按原图像素比例追加画布；预览和 JPEG 共用布局。手动机型／参数只影响边框显示；不修改原图。缺失字段自动隐藏，原始拍摄时间显示在边框内，原有保存位置与相册时间规则沿用。`PhotoExifRationals` 保留 JPEG 内原始曝光、光圈及焦距的无符号分数，避免框架写入 /10000 导致高速快门精度丢失。

| 要素 | 实际实现 |
|---|---|
| 页面／按钮／图形 | Android Views、系统字体、现有 AppIcon，真实可点击控件 |
| 三款边框 | Bitmap／Canvas；原照片内容完整保留，追加边框画布 |
| 尼康 Logo | 官方 Nikon SVG 的真实路径派生；透明白／黑字标及黄色方标 |
| 侧栏参数 | Tomorrow ExtraBold Italic，SIL OFL 1.1，真实斜体字体 |
| 其他品牌 | EXIF 机型文字及中性品牌文字；内置尼康／富士／索尼／佳能选择，支持自填 |
| 素材来源 | `app/src/main/assets/photo-borders/source-manifest.json` |

参考图的原参数字体未识别；Tomorrow 是接近的方正斜体，不能宣称逐像素同一字形。其余品牌没有伪造官方 Logo。所有设置界面文字为原生 sp 字号，不使用设计稿切片。

## 验证边界

最终包及原生证据见 `docs/validation/photo-borders-89/`。测试使用独占只读模拟器、用户桌面照片裁剪和明确构造的 EXIF；不认证实体相机、手机安装、生产网络、FPS 或 TalkBack。最初候选的系统全屏提示遮挡图不可用作视觉验收，已归入历史范围。另一个任务的相册占位实现独占 `LocalAlbumPanel`／`PhotoPlaceholder`，保持原有来源链和缓存逻辑；其证据独立列示。
