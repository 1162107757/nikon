# 视觉预览验证

此文件记录原生实现之前的网页提案验证。随后用户授权“开始实现”，0.4.0-beta 的 Android 构建、设备截图及安装证据另见 `dist/nikon-usb-0.4.0-beta-VALIDATION.txt`，不与下述网页证据混用。

## 本轮：连接集中到设置

2026-10-16，Codex 内置 Chromium 浏览器，以本机静态 HTTP 服务打开独立设计稿。

- 1440 × 1040：浅色与深色的预设库、相册、设置三屏。保存 `preview-settings-light.jpg`、`preview-settings-dark.jpg`。
- 390 × 1000：设置页和 Wi-Fi 地址抽屉。保存 `preview-settings-mobile.jpg`、`preview-wifi-settings.jpg`。文档宽度为 390px，设置滚动区宽度与内容宽度相同；无横向溢出。三个底栏按钮实测约 93 × 56px。
- 点击预设页底部“设置”可进入设置页，再点“预设”可返回。三个根页面均保留预设 / 相册 / 设置导航，预设与相册移除连接方式卡片和按钮。
- 在设置断开连接后，预设与相册同步显示“未连接”，相机照片显示引导说明；切换“已下载”仍有三张离线示例照片。
- Wi-Fi 抽屉可编辑 IP 与端口，默认 192.168.1.1 / 15740。输入 999.1.1.1 后连接会显示校验提示；恢复有效值后连接演示更新三个页面状态。
- USB 抽屉明确用途为预设导入。演示连接 USB 后，相机照片仍显示未连接，并解释相册需要 Wi-Fi，预设连接状态保留。
- 重置可恢复默认 Wi-Fi 示例。点击相册第一张照片进入沉浸查看，仍有轻量预览、下载原图和返回相册操作；返回成功。
- 复核修正后，选中相机第 6 张再切“已下载”，会退出多选并恢复普通三项底栏；没有旧选择计数残留。沉浸查看按 Enter 隐藏工具后，返回按钮不再出现在可访问角色查询中；再次 Enter 恢复后可正常返回。源码同步设置 `inert` 与 `aria-hidden`。
- 浏览器控制台错误记录为空。`node --check preview.js` 通过，三个源文件尾随空白扫描无匹配。该目录尚未跟踪，未将 `git diff --check` 当作这些新文件的验证证据。

独立完成复核：`settings_finish_review` 检查本轮四张截图及 HTML / CSS / JS，认为视觉与导航符合范围；指出的来源多选残留和不可见工具焦点问题已修正，经浏览器核对和独立源码复核后结论为通过，无剩余材料级缺陷。

系统偏好分支本轮未切换验证；没有完整无障碍验收。原生字号、TalkBack、真实照片比例、设备模糊性能、相机连接及协议均不在本轮实测范围。所有连接与下载操作为本地界面演示；没有替换 Android Views、打包或安装 APK。
