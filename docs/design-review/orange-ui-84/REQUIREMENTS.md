# 84 · 橙光原生界面

用户在确认 [详细交互稿](../insurance-inspired-20261023/detailed/index.html) 后要求“开始按照设计图实现一个全新界面的 app”。本轮是原生 Android Views 实现，使用真实的目录、相机控制器、照片库与编辑管线。访客模式为 Operate。

## 视觉约定

- 预设首页的橙／杏光区、紧凑标题与在线／我的分段；连接状态、分类、真实数量、双列模板预览和一个加号。
- 全局暖灰白表面、白色分组、炭黑主动作、杏色选择态。系统字体、sp 字号、原生权限／文件选择器／对话框及返回。
- 紧凑屏四入口底栏；宽屏侧栏；横屏与字号 1.3 保持可用。现有深色选项保留为完整暖石墨配色。
- C1–C9 原生槽位网格，保持真实占用信息、兼容参数及覆盖前二次确认。
- 同步的相机／直播／已下载、RAW 文件与接收记录继续存在；相册仍默认 App 内，手机来源、授权、PNG、选择菜单与加号保持实际行为。
- 编辑器保持照片画布、224dp 工具与横屏右侧 300dp；13 项调节、构图、配方、草稿、撤销／重做继续使用已有实现，工具强调改为杏色。
- 账号、投稿、评论、消息、更新、Wi-Fi／USB 入口继承同一组件语言，保留实际登录与能力边界。

## 功能底线

NP3 仍不允许相机写入；不确定的导入结果只读核对。相机／直播接收默认 App 内，编辑输出默认手机相册，场景与项目记忆、任务冻结目标、有效同版本复用和明确“另存新副本”沿用 83。根页切换不停止共享连接与直播。完整 JPEG 才能编辑；照片、配方不会因界面替换自动上传。

本轮不更换安装标识，不清理用户数据，不自动发布版本。预览原型中的评审目录、状态控制器、示例账号／相机／照片均不进入生产 App。真实数据由既有实现提供。

## 验证边界

使用任务专用只读模拟器，通过原生 View 和既有回归夹具检查手机、大字号、横屏、深色及平板。截图必须来自最终 APK；合成 NCP／JPEG／PNG／结构 NEF、槽位夹具与真实服务／硬件验证明确区分。独立视觉复核和设计文档在最终修正后完成。证据见 [验证目录](../../validation/orange-ui-84/)。
