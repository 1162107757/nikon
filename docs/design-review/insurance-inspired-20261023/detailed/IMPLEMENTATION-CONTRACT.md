# 从设计到原生的对照标准

本文件用于视觉方案被确认后的实施验收。当前没有批准替换正式 App 的全局设计，也没有修改原生源码或发布新版本。

## 不可在接入时省略的内容

- 四个根入口及真实来源层级：预设在线 / 我的；同步相机 / 直播 / 已下载；相册 App 内 / 手机；设置连接与账号偏好。
- 导入前检测、C1–C9、兼容适配、覆盖二次确认、结果不确定时只读核对。NP3 相机导入继续明确拒绝。
- 照片权限的全部 / 部分 / 拒绝 / 撤销；PNG 白底工作副本确认；相机预览与完整本地原图的编辑边界。
- 编辑器 13 项参数、精确输入与错误、帮助、撤销 / 重做、原比例画布、暂存构图、配方、版本与草稿。
- 保存目标、同版本复用、明确新副本、任务取消 / 重试；切换页面不能停止共享连接和直播。

## 视觉尺寸必须有对应的原生证据

| 对照项 | 设计基准 | 原生核对 |
| --- | --- | --- |
| 内容宽度 | 手机主体 390 × 844 的设计空间，主边距 20 | 按实际设备 dp 适配，不按浏览器像素硬编码 |
| 操作触区 | 常规主要动作与图标 48，悬浮加号 54 | 即使图标视觉较小，也保留至少 48dp 触区 |
| 列表与照片 | 日期分组、真实文件名、三列方图；不以装饰统计占主要空间 | 使用实际照片与版本数量，不使用设计固定文案 |
| 预设首页 | 约 180 高的橙光标题 / 来源区，后接状态、分类与真实内容 | 不恢复首版的大面积收藏统计卡，照片仍占首屏主体 |
| 卡片材质 | 灰白底、白色层次、克制软阴影、炭黑主按钮 | 先实现轮廓、密度与文字；模糊性能不佳时使用足够实色材质 |
| 照片编辑 | 黑色画布与贴边固定 224dp 工具；进入编辑隐藏根导航 | 竖屏大图，横屏右侧 300dp；工具切换不改变照片位置 |
| 返回与取消 | 返回原入口、保留当前来源 / 模式 / 草稿；构图未应用不提交 | 使用系统返回和实际 View 事件确认，不能只检查按钮存在 |

## 需要并排核对的状态

预设正常与离线；NCP 空槽 / 覆盖 / 不确定；NP3 禁止导入；同步断线与传输；直播等待 / 接收 / 保存 / 处理 / 失败；相册未授权与部分授权；编辑滤镜与 13 项调节；构图取消与应用；导出 App 内零新增、重复保存零新增、明确新副本新增；投稿退回；消息失败保留未读。

原生交付不能用浏览器截图替代。每组对照说明实际版本、设备尺寸、字号、夹具与验证范围。若需改变已确认布局，应列出具体差异再讨论，不能在接入时悄悄删掉页面和状态。
