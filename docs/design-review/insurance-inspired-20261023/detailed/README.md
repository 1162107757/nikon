# Huevia 橙光 · 功能细化稿

用户要求结合实际功能重新细化，担心第一版只停留在外观。本版本保留已选参考的橙光、灰白与炭黑按钮，将当前工作区的四个根入口展开为 22 个主要页面和 75 个可选择的状态。

预览：[打开详细交互稿](http://127.0.0.1:8786/detailed/index.html)。若服务未运行，从项目根执行 `node docs/design-review/insurance-inspired-20261023/serve.mjs`。

上方切换「页面总览」看四个主页面；「交互体验」可在左侧目录选择完整页面，在手机内操作，在右侧状态演练切换加载、失败、权限与恢复场景。窗口较窄时说明移至手机下方，手机上目录变为横向滑动。

## 重点流程

- 预设：在线 / 我的、完整分类、详情 / 曲线 / 评论；NCP 先下载再检测、读取 C1–C9、兼容适配、空槽与覆盖确认、结果不确定时只读核对。NP3 手机预览与相机导入边界明确分开。
- 同步：相机照片 / 照片直播 / 已下载，独立 NEF、相机纯预览、项目与默认预设、接收 / 保存 / 效果处理、接收记录及失败重试。
- 相册：默认 App 内 / 手机，系统加号与更多操作、未授权 / 部分授权 / 撤销、PNG 白底工作副本、日期 / 文件名 / 版本、多选与批量。
- 编辑：原比例大图、固定黑色紧凑工具、13 项调节与精确值、撤销 / 重做、构图取消 / 应用、配方命名和管理、原图 / 版本 / 草稿、保存位置与重复版本复用。
- 设置：Wi-Fi / USB、后台保护、游客与示例登录 / 注册 / QQ 衔接、个人同步征询、投稿审核、消息回复和更新渠道。
