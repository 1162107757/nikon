## 工程与素材

`node --check` 检查 preview.js、serve.mjs 通过；HTML、CSS、JS、摄影 atlas 的本机 HTTP 请求均返回 200。PNG 来源扫描为 1 张素材、0 项缺失；atlas 原有来源文件和内嵌元数据保留。界面图标为源码内一致笔画的 SVG。

Impeccable 静态检测器只运行一次。当前环境缺少 htmlparser2／css-select／css-tree／domutils，退化为正则检查，不能据此声称计算对比度或完整 DOM 审计通过。唯一报告为未使用的进度宽度动画，已移除该布局属性动画。
