## 已确认的方向

用户希望点击照片后采用参考图中“大图预览、底部选择滤镜”的编辑布局，并已选择首版只做 **滤镜＋强度＋导出**。保留 Huevia 的蓝色操作色；图片查看和编辑区域使用固定暗色画布，降低环境色对看图的干扰。沿用现有原图、效果版本、相册保存与 NEF 导出能力。

审核图展示同一方案的三种状态，而不是三个待选风格：① 常驻底栏编辑；② 展开选择全部本地滤镜；③ 导出确认。滤镜名称、强度、照片编号及数量均为设计示意；生成图中的调色效果不作为算法精度证据。

用户补充的首版必需项：“每张图设置好滤镜后也要支持批量导出”。批量导出必须保留每张照片各自的滤镜和强度，不能统一替换成当前照片的一套设置。

## 目标与入口

- 从“已下载”、直播项目和相机照片点击大图进入同一查看／编辑页。图片仍是页面主角，底部可直接换滤镜，不再先跳到独立的整页预设选择器。
- 已完成的本地 JPEG 可立即调色；相机端仅有预览或原图未收全时，可正常看图，滤镜区提示先下载原图。
- 进入照片时恢复该照片当前版本；若有尚未导出的编辑草稿，恢复其滤镜与强度，并显示“未导出”。草稿与已生成效果版本分开保存。
- 底部只展示当前账号／游客可见的本地预设，保持已有账号隔离。在线发现与下载仍由预设库承接，不能把其他账号缓存列进来。

布局基准为约 412 × 915dp 的竖屏，底部面板约 240–280dp，高度随字体和安全区适配。图片区域使用剩余空间等比适应。滤镜卡片约 68–76dp 宽，照片预览不使用发布者样片；缩略图可裁切，主图保持完整。所有操作的触摸目标至少 48dp。

首版只提供滤镜编辑，不加入 AI、人像美容、裁剪或手动曝光／色温面板。参考产品的底部工具栏不照搬为未实现的功能入口。

## 图 02：展开全部滤镜

- 在当前编辑页上方展开约 60–70% 高度的面板，上方仍能辨认照片与顶部导出入口；退出此面板返回同一编辑草稿。
- 面板提供标题、关闭、搜索和分类，下面为三列可滚动的当前照片效果网格。
- 分类与滚动位置保留。点击可用滤镜后选中并收起到横向滤镜条，主图显示新效果；不保存相册、不生成永久效果文件。
- 当前选中项有蓝色边框与勾选。“原图”同样可选；不支持的预设仍可见，显示“暂不支持”与原因入口，不生成假效果，不把失败当原图显示。
- 搜索只匹配当前可见本地预设的名称及分类；无结果展示清空搜索入口。无本地滤镜时提供“去添加滤镜”，取消后保留原图与当前照片位置。

## 图 03：导出确认

- 点击右上角“导出”后弹出底部确认面板：当前效果小图、滤镜名称、强度、JPG、原始像素尺寸，以及“保存为新照片，原图保留”。
- 唯一主操作为“保存到相册”。取消仅关闭面板，保留编辑草稿。
- JPG 保存当前照片的当前滤镜与强度；完整尺寸生成效果，沿用当前 JPEG 95 / sRGB 输出与已有捕获信息保留策略。
- 已有 NEF 导出能力放在次级“导出相机原始 NEF”入口，仅在可可靠取得原文件时可用，并说明“不包含手机滤镜”。没有来源证据时按现有 RAW 规则明确选择，不靠同名推测。
- 成功后轻提示“已保存到相册”，新效果加入该原图的版本列表，不增加一张重复的原图卡片。同一原图、配方、强度与模型重复导出时复用已验证结果。
- 处理时显示真实阶段与可用的实际进度，防止重复提交；失败保留草稿、原图与已完成的结果，并提供重试。原图不改写。

## 批量导出（已确认的首版需求）

- 用户可以逐张进入照片设置不同滤镜和强度，返回相册后多选照片，点击“批量导出”一次保存。返回列表与重新进入照片时保留各自的编辑草稿。
- 相册卡片应反映该照片的当前预览，并以“已调整／未导出”等轻量标记帮助识别；不为尚未导出的草稿提前创建永久效果文件。
- 批量导出按每张照片自己的编辑设置执行，不要求用户再选一份公共预设，也不能将当前照片的滤镜批量覆盖到其他照片。现有“批量套用同一预设”是独立动作。
- 每张照片有草稿时按草稿导出；没有草稿时导出该照片当前选中的已保存版本，当前选择原图时导出原图。确认信息展示总张数，说明“保留每张照片的滤镜设置，原图不变”。
- 开始任务时冻结每张照片的原图身份、配方内容、强度与模型版本；任务开始后的编辑只影响下一次导出，避免排队期间设置串用。
- JPG 按每张照片的原始尺寸生成或复用效果并保存相册。NEF 批量导出沿用原文件规则，不带手机滤镜，不能用该入口替代带效果的 JPG 导出。
- 显示总体张数、当前照片、真实阶段与可用进度；支持取消后续任务。逐张统计成功、失败、复用与未处理项，单张失败保留其他成功结果，提供只重试未完成项的入口。
- 同一照片以相同配方和强度重复导出时复用已验证效果；已删系统相册副本时重新发布。不同照片、不同滤镜或不同强度不得错误复用结果。

验收例：照片 A 设置“冷杉绿调 70%”，照片 B 设置“暖阳胶片 40%”，照片 C 保持原图；退出、重进后多选 A／B／C 批量导出，分别得到 A 的 70% 效果、B 的 40% 效果和 C 的原图。批量结果应与逐张导出的效果及尺寸一致，三张设置互不串用，所有原图字节保持不变。

## 编辑规则与技术边界

1. 点滤镜及拖动强度仅产生预览，**导出才提交新的效果文件与公开相册副本**。这需要为单张编辑增加临时预览／草稿，不直接复用“选择后立即开始永久批处理”的旧交互。
2. 换滤镜始终从经过校验的原图生成，不在上一个效果上叠加。进入已有旧效果时先核对来源链；无法确认时明确提示，不能猜原图。
3. 强度为 App 自身的混合比例：0% 是原图，100% 是当前完整配方效果。它不改写 NCP／NP3 原文件，也不表示尼康原生参数。首版混合规则、预览与导出须共用同一实现。
4. 目前已有的是完整强度的 NCP／NP3 近似模型。强度调节、单张草稿、底栏当前照片缩略图和延迟导出是本次方案需要新增的能力，不能当成现成已上线功能。
5. 强度必须加入效果／缓存／去重身份；旧的满强度效果继续可识别、可比较、可复用。不同强度不能错误复用为同一效果。
6. 预览只按可见项生成，优先当前主图；快速切换时以照片身份、预设身份及请求序号丢弃旧结果，旧任务不能覆盖新选择。滑杆拖动的降采样预览不得替代完整尺寸导出。
7. 横向滑动滤镜只滚动底栏；在主图滑动才翻照片。图片放大时先处理拖动，沿用当前边界翻页规则。按住原图、页面失焦和多指取消时必须正确恢复效果。
8. 单击图片可暂时隐藏工具；再次单击恢复原面板状态。返回优先关闭展开层，然后退出看图；已选择的滤镜与强度作为草稿保留，不自动导出。
9. 手机预设效果仍标注近似性质，格式名不占用主要编辑空间；配方详情／帮助保留完整支持范围。NEF 不在此流程中显影。
10. 单张编辑不改变直播项目的默认预设，不向相机写入预设，不自动同步设置到其他照片。批量导出由用户明确多选触发，分别读取各照片自己的设置。

## 必须覆盖的状态

| 状态 | 页面响应 |
| --- | --- |
| 原图就绪、未选滤镜 | 原图卡选中，强度禁用，导出可保存当前原图。 |
| 原图下载中／仅相机预览 | 主图可看；滤镜区说明需完整原图，提供明确下载动作。 |
| 滤镜预览加载 | 保持上一张已就绪主图，选中卡显示加载；新效果就绪后替换，不能整页闪白。 |
| 拖动强度 | 数值跟随，轻量预览；松手更新稳定预览，不生成系统相册照片。 |
| 滤镜不支持／文件损坏 | 卡片标记并给出具体原因，当前有效预览保留。 |
| 断网 | 本地配方与已保存原图可继续调色和导出；预设库联网动作显示实际不可用。 |
| 切照片 | 恢复每张照片自己的草稿／版本，不能把前一张异步结果贴到后一张。 |
| 多张照片有不同设置 | 多选后按每张独立的滤镜与强度批量导出，不弹出统一预设选择器覆盖设置。 |
| 批量导出部分失败／取消 | 成功项保留，列明失败和未处理项；按启动时冻结的每图设置重试未完成项。 |
| 已有相同效果 | 导出复用完整结果，核对系统相册副本；已删公开副本时可再次保存。 |
| 保存失败／内存不足 | 保留原图与草稿，显示可重试原因，不静默降低图片尺寸。 |
| 大字号／横屏 | 文本不挤压关键按钮；横屏可将滤镜面板放到右侧，不能把主图压成不可用的窄条。 |
