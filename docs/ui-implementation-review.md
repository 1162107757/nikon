# 0.2.1-beta 界面修正与检查记录

用户要求按已审核的红白预设、导入和相册设计实现。0.2.0-beta 交付时没有可用手机或模拟器，仅完成代码与构建检查；用户连接手机后指出实际界面偏差明显。0.2.1-beta 根据运行截图逐项修正，不改变已核实的 USB 导入后端、PTP/IP 协议或预设持久化逻辑。

## 本轮修正

- 首页：来源切换由整块粉色选中背景改为白底红色下划线；USB 灰栏恢复相机图标、两行说明和红色文件添加操作；删除未配置在线库的重复提示。
- 导航：根页底栏保留“预设 / 相册”两项，白底、细顶线、图标和文字居中，选中仅使用红色；预设详情、导入确认及结果、照片详情和无线引导隐藏底栏。
- 按钮与卡片：清除原生 Button 的默认阴影、动画和背景着色；使用实红主操作、白底细描边次操作和文字辅助入口。首页卡片按 1.68:1、预设详情按 1.25:1 展示图片或实际缺图占位。
- 详情与导入：文件来源和兼容信息改为灰卡；配套样片关联改为文字入口；确认页按预设摘要、相机、空槽与适配摘要分组，成功页居中显示红底白勾和读回核对结果。相机未连接时不伪造确认或成功画面。
- 相册与连接：连接条压紧，来源标签使用下划线；选择等轻操作改为文字。无线引导补齐连接线稿、三块灰底步骤卡、红色数字、菜单及手机示意图、已下载入口；实际 IP 和端口设置维持折叠入口。

## 构建与既有检查的边界

当前版本为 `0.2.1-beta`、versionCode `11`，产物为 `dist/nikon-usb-0.2.1-beta-debug.apk`，205346 字节，SHA-256 为 `05708a99dcf4ed4fa095cd195edd035fb9d5b71eb90facbcf9d230b01d99c3ed`。最终包已完成构建和覆盖安装，手机 `base.apk` 校验值与该值一致。构建、签名及安装命令等细节见 [0.2.1-beta 验证记录](../dist/nikon-usb-0.2.1-beta-VALIDATION.txt)。

前轮 0.2.0-beta 通过 Android SDK 35 / JDK 17 编译、资源打包和 D8；8515 项协议、生产后端模拟与持久化检查通过，APK v2/v3 签名及旧版证书一致性已核对。原始配方、私有研究资料及概念样片未包含在 APK。完整结果保留在 [0.2.0-beta 验证记录](../dist/nikon-usb-0.2.0-beta-VALIDATION.txt)。本轮仅修改界面与版本包装，未重复运行这 8515 项后端检查。

代码中的导入保护继续保留：确认前读取空槽、再次检查目标、单次登记和精确读回；写入结果不明时保留待核对记录，先只读核对同一台相机；高级诊断不能绕过未确认写入的保护。

无线部分为标准只读 PTP/IP，没有尼康专有配对认证。Z6II 的实际无线兼容性仍待相机实测。当前交付仍为可安装的测试版，不以布局修正或旧有自动检查代替相机功能验收。
