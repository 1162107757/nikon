# 个人预设云端

0.11.4-beta / Android61，后台1.5.0，迁移011。同步预设原文件、名称、原文件名、分类和简介；模板、自选样片留在本机。游客可继续本机使用，登录时询问是否同步未归属账号的原有预设；登录后新导入、下载、分类修改自动排队。退出和切换账号不会把另一账号的缓存上传，个人条目在我的列表和选择页按账号筛选。

手机保留离线副本及持久同步队列。前台恢复、登录变化、新增／删除／修改和手动操作触发同步；网络错误不切换相机 Wi-Fi 或进程网络绑定，不影响原文件。状态栏明确“待同步”，点击可重试或打开说明。服务器版本检查防止覆盖其他设备的更新，用户选择使用云端信息或保留本机更改；相同文件原字节按 SHA-256 去重。响应丢失后按元数据与版本核对，不重复上传同一内容。

服务接口 `/personal/presets` 和 `/personal/presets/:sha256` 全部要求普通用户 Bearer 登录；身份取自有效服务器会话，客户端不能指定归属。数据表与 RPC 对 anon / authenticated 禁用，由服务端调用；私有存储对象放在 `personal/<user-id>/<sha>.preset`，不写入公共 catalog、社区投稿资产表或公开文件接口。下载每次鉴权并核对大小与 SHA，响应 no-store；数据库和安装标识／来源限流同时执行。

当前上限：单文件1 MiB，每账号128 MiB已登记文件、5000条（含删除同步记录）；每小时120、每天500次上传尝试，并保留原全局／来源／安装标识请求预算。删除使用版本化同步记录，阻止其他设备的旧缓存自动重新上传；服务器停止提供该文件，但私有原对象和删除记录仍保留，空间不在当前版本立即回收。另一设备收到删除状态时隐藏离线条目，保留可能被拍摄项目引用的设备文件，不自动破坏项目处理。模板和样片备份、存储空间回收及后台个人库管理不在本版范围。

接口与真实 PostgreSQL 验收覆盖账号隔离、重复请求、并发信息冲突、删除状态、额度与私有权限。生产验证只创建两个精确测试身份及一个私有合成 NCP，验证完成后移除测试会话、记录、身份和对象；不向现有用户发送消息或发布任何测试预设。见 [验证记录](validation/personal-presets-61/README.md)。
