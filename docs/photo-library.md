# 照片身份、版本与相册保存

适用版本：Huevia 0.9.13-beta 起。交付和实测范围以对应 `dist/*-VALIDATION.txt` 为准。

## 用户可见行为

- “已下载”和直播项目按原照片归组；同一原图与多个预设效果共用一张卡片，角标显示版本数量。日期使用原照片日期。
- 全屏查看器的版本按钮可选择原图或某个预设效果，选择会保留。左右滑动继续显示各照片选定的版本。
- 按住“原图”显示经过来源记录校验的真正原图，松开恢复当前效果；旧的多次叠加效果也追溯到原图。
- 原图下载、直播接收继续自动保存到系统相册。效果单独保存，重复选相同原图和预设复用已有结果。
- 查看器核对系统相册副本后显示“已保存”或保存／重试操作。用户从系统相册删除副本后，返回 App 可重新核对和保存。
- 删除照片时删除该原图、全部效果及对应系统相册副本；版本菜单可仅删除当前效果。确认弹窗区分范围，相机存储卡保留。

## 0.11.1 的导出与进度入口

查看器使用紧凑的“导出”按钮，先选择 JPG 当前版本或相机原始 NEF。JPG 继续保存当前选中的原图／效果版本；NEF 保留相机文件的原始字节，不带手机预设效果。相机照片支持批量选择后导出 JPG 或 NEF；“RAW”入口可单独查看相机 NEF 与已保存 NEF。

新下载的 JPEG 会另存经过校验的相机来源记录，用于可靠查找配套 NEF。较早下载的 JPEG、来源不明确或候选不唯一时，需进入 RAW 列表明确选择，不靠文件名猜测。读取新的相机 NEF 需先停止照片直播；已经保存的 NEF 可以离线再次保存到系统相册。详见 [RAW 原文件导出](raw-original-export.md)。

手动套用预设显示整体进度、当前张数和处理阶段；直播自动套用在固定位置显示进度，对应照片也显示进度角标。直播项目、当前照片与下方照片列表使用同一个滚动区域，向下浏览后提供“顶部”按钮。进度更新保留布局高度和当前位置。

## 身份与旧文件

`PhotoOriginalStore` 以完成后的 JPEG 字节 SHA-256 确认原图身份。已认证相机 GUID 的完成记录允许在描述符匹配时直接复用；无有效 GUID 的跨会话连接先接收并校验内容，避免把同型号／同地址相机当作同一台。中断、临时文件和不完整记录不能作为完成结果。

`PhotoLibraryCatalog` 只对校验完成的来源链归组，不靠文件名相似度推断原图。历史重复原图保留所有私有路径，列表合成一个逻辑原图；缺失、损坏或循环的效果来源独立显示，不能假装已找到原图。列表使用独立工作线程及有限文件指纹缓存，渲染、删除和公开发布各自保留严格校验。

效果身份包含原图内容、预设内容及渲染模型。两个不同预设即使产生一样的 JPEG 字节，仍是不同效果版本。同一效果在受支持的内部／外部目录存在多个旧路径时，按相同效果键及完整内容校验识别别名，复用完成结果和系统相册 URI。

版本名称与当前显示选择保存在私有记录中，重开 Activity 后恢复。旧文件不自动迁移、改名或物理删除；本轮归组不会自动清理历史重复文件。

## 发布与删除

新发布使用 Huevia 可读文件名，沿用现有“相机预设”相册目录及项目子目录。已有发布记录继续使用其原 URI、名称和目录；多个项目中的同一原图共享已核验的系统相册副本，项目成员关系独立保留。

`PhotoAlbumSaver` 串行执行公开副本状态查询和发布。已保存状态同时校验私有内容与公开副本；原图和严格同键的效果别名可复用公开记录，状态不只依赖私有文件是否存在。

删除入口先获得完整目录快照，再把选择展开为全部成员。目录未就绪时阻止删除并提示重新读取，避免承诺整组删除却只删代表文件。仅删除效果时包含该效果的所有别名。后台先处理效果，再处理原图；失败或尚未选择的有效派生依赖会保护来源，部分失败明确报告，不冒充全部成功。

所有自动清理仅针对本次任务拥有的未完成临时文件；历史原图、旧效果与旧系统相册副本不会因升级被批量清除。

## 验证边界

Host 检查覆盖身份复用、完成记录、来源链、别名、发布状态和删除保护。独立 Android 原生检查使用自建 JPEG 与真实 MediaStore，验证卡片归组、版本切换、按住对比、选择持久、删除取消／确认及无关照片保留。测试文件和其准确 URI 在完成后清理，既有模拟器基线内容逐一核验未改变。

上述证据不等于真实相机、真实用户照片全量迁移或厂商后台限制验收。后台连接的独立实现与边界见 [Wi-Fi 保留说明](validation/background-wifi-retention-20261018.md)。
