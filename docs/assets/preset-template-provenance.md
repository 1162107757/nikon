# 预设模拟模板来源

`app/src/main/res/drawable-nodpi/preset_template.png` 是 2026-10-16 使用 OpenAI 内置 image_gen 工具生成的合成照片。完整提示词保存在同目录 `preset-template.prompt.txt`，并嵌入源 PNG 的 `impeccable:prompt` 文本块。保留生成像素，未做人工调色。

用途是内置统一色调参考模板，包含肤色、蓝色湖水、绿色植物及红黄物体。它不是尼康相机样片，也不是任何 NCP 的效果证明。应用在后台将可解析 NCP 参数应用到该模板或用户自选模板，标注“模板模拟”。
