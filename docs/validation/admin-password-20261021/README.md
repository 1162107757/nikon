# 后台管理员修改密码 · 2026-10-21

实现范围：后台右上角“修改密码”，验证当前密码并输入两次新密码。保留管理员 16–256 字符策略，原样保留空格和符号。成功后撤销该管理员全部会话并清除当前 Cookie，提示用新密码重新登录；其他管理员和普通 App 用户不受影响。
