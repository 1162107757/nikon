## 实体手机对照

使用现有用户数据检查了预设首页／真实 NCP 详情、同步未连接态、已有直播项目、App 内相册、已有 JPEG 编辑器、调节页、构图打开／返回取消，以及浅深色设置和横屏。用户原有 16 份预设、相册内容和直播项目仍在；没有向手机加入模拟器测试夹具，没有触发相机写入、照片导出、登录或发布。进入调节和构图仅检查界面，没有改变参数或应用构图。

手机截图为原始 ADB 截屏，未修图，目录为 [physical](physical/README.md)。其中 `editor.png` 是在线滤镜仍在加载时的初始状态；稳定编辑界面依据 `editor-adjustments.png` 和 `editor-after-crop-cancel.png`。设备实际保留的 1080×2376 / 408dpi 覆盖值和字号 1.0 未被重置。

检查期间临时启用 USB 充电保持唤醒；结束后已恢复原值 0，息屏仍为用户原来的 1,800,000ms（30 分钟），外观恢复“跟随系统”，旋转恢复原来的 0 / 0，同步来源回到“相机照片”。

## 范围与历史

这轮没有验证实体相机传输／登记、传感器 RAW、实时在线目录／登录、FPS、显示颜色标定或 TalkBack。相册文件选择和权限夹具只证明实际 View 到平台派发／取消及库处理路径，不表示已全面审核外部系统界面。旧版本的测试、相机反馈和公开发布记录不累计为本轮证据。
