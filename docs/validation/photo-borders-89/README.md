# 89 / 0.18.0-beta 照片边框

本地测试包：[huevia-0.18.0-beta-debug.apk](../../../dist/huevia-0.18.0-beta-debug.apk)。用户已批准三款边框设计并明确开始实现；小机型文字／小相机图形沿用最终稿。需求、实现边界及素材见[实施约定](../../design-review/photo-borders-20261024/IMPLEMENTATION.md)。本轮没有公开发布或安装到实体手机。

最终候选 SHA-256：`1f74ece275423198208750b804e7dad8e72c443b881c02eccb85eea9c4cd2ba0`。当前原生报告均核对设备实际安装 APK 的相同哈希及89版本。最终修正的独立评分见 [FIX-VERDICT.md](FIX-VERDICT.md)；初审 [FINISH-REVIEW.md](FINISH-REVIEW.md) 属于 d433 候选，不能作为当前包的完整认证。

## 行为

- 原生编辑器增加“边框”，提供无边框／模糊居中／模糊侧栏／白底信息。主体照片完整保留，边框在外追加画布；预览、缩略图和完整 JPEG 使用相同的比例排版。
- 原图 EXIF 自动填充品牌、机型、焦距、光圈、快门、ISO和拍摄时间；可手动选机型、自定义机型、补填和隐藏字段。机型栏11sp，相机图形14dp，整行48dp。手动展示不会改写原图。
- 边距、圆角、阴影、模糊程度和尼康 Logo 版本可调。官方尼康字标／方标由原始矢量路径派生，侧栏使用 Tomorrow ExtraBold Italic（OFL）；原参考字体未识别，字形为近似匹配。其他品牌使用中性品牌文字。
- PED4草稿保留边框并兼容PED1／2／3，旧数据默认无边框；边框进入撤销／重做、冻结设置、缓存身份和保存状态核对。批量“套用效果 → 照片边框”逐张读取自己的原图；单张与批量配方不清除边框。
- 处理原始曝光等有理数，避免系统EXIF写入把1/640量化成近似值。输出方向归一，照片原始字节保留；保存位置、相册排序、新副本规则沿用既有实现。

## 初审修正及历史

初审指出两个P2：子输入框可能跨绑定写入、非尼康品牌文字可能越过Logo槽位。修正加入owner＋绑定代次＋原图身份、统一子对话框关闭与回调守卫，以及品牌实际宽度测量／上限。手机验证保留旧按钮后重新绑定相同原图，旧按钮和Logo回调均无修改；合成owner变化只证明守卫，不认证真实账号登录流程。四品牌和长名称通过实际导出JPEG检查。

最初 e640 候选的全屏教育提示遮挡截图不可用于视觉验收；保留 `initial/` 仅作历史。1e026／b53等中间候选也不是最终证据。最早被Android EXIF写入量化的测试数据已改为精确1/640分数夹具，最终检查同时验证源值、展示值与输出值。初审d433记录与最终修正后的1f74状态分开；旧文件名对应的原生图已按最终包重新截取。
