# App 账号与登录

## 0.10.2：用户头像

“设置 → 账号 → 我的账号”支持点头像或“修改头像”，从系统图片选择器选图后确认预览，也可恢复默认。客户端在后台校正 EXIF 方向、居中裁成正方形并生成 512px JPEG，去掉来源图的位置等 EXIF 数据；选图、取消、失败不会改变当前头像。退出或切换账号后，旧选图结果与旧网络回调不能覆盖新账号。

密码账号没有头像时显示统一的圆形人像图标。QQ 账号默认使用 QQ 资料头像；自行更换后再次 QQ 登录保留自定义头像，恢复默认时使用最近一次 QQ 资料头像。预设评论与回复共用同一头像组件，加载失败回退默认图标，不影响文字阅读。

头像上传须登录，服务端要求用户版本匹配，并在读取图片前持久预留账号、安装、来源及全局配额；仅接受 64–1024px 正方形、最大 1 MiB 的完整 JPEG。图片存入现有私有桶，公开地址只提供活跃用户当前已提交头像。客户端读取公开头像不附带账号凭据、不跟随重定向。007 迁移保留旧账号与 QQ 头像来源，支持重复运行；当前全局预留容量上限为 8 GiB，达到后须由运维核查，不能通过等待日配额恢复解决。

0.9.8-beta（47）在此基础上增加 QQ 登录：设置 → 账号 → QQ 登录，明确同意隐私说明后才初始化官方 SDK。首次 QQ 登录建立独立账号，不自动绑定或合并现有密码账号。服务端已配置 AppID `1105984855`；平台包名与签名匹配及真实 QQ 授权尚待用户完成验证。登录说明、SDK 第三方信息和平台配置见 [QQ 接入说明](qq-login.md)。账号操作按钮已移除默认抬升阴影，保留圆角、按压反馈和按钮内加载状态。

账号入口位于“设置 → 账号”。用户已确认保留游客模式；既有预设、相册和相机流程不要求登录。账号不提供照片、预设或项目的云同步。原账号密码接入的版本与验证记录保留在下方历史验证部分。

## 登录入口与布局

0.9.10-beta（49）落地本方案。原生界面、加载与返回检查见 [交付记录](../dist/nikon-usb-0.9.10-beta-VALIDATION.txt)；本轮不包含真实 QQ 授权验收。

登录页采用用户审核的“轻简入口”方案：以 Huevia 品牌和 QQ 登录作为首屏主入口，账号密码表单按需切换显示，注册使用文字入口。顶部提供游客使用入口，底部保留 QQ 登录与隐私说明及登录帮助。密码输入框内提供显隐操作，不再单独占用一行复选框。登录帮助说明网络要求，避免首屏持续显示较长提示。

切换登录方式、离开页面或切到后台时清理密码，用户名可作为当前操作的草稿保留；密码不写入持久化存储。注册与密码登录保留校验、错误反馈和按钮内加载状态，处理中禁止重复提交或切换登录方式，返回操作仍可退出账号页。QQ 授权、账号恢复和服务端登录使用各自对应的状态提示。

QQ 主入口仍须先展示隐私说明，只有点击明确的同意操作后才初始化 SDK 并发起授权。取消说明或 QQ 授权后仍可使用其他登录方式或游客模式；从 QQ 返回应用按原有生命周期接收结果，避免重复提交或误取消授权。首次 QQ 登录建立独立账号，不自动合并已有密码账号。

## 注册与登录

1. 在设置的“账号”分组打开未登录入口，可使用 QQ 登录、切换到账号密码登录，或通过文字入口注册新账号；也可选择游客使用。
2. 用户名为 3–32 位 ASCII 字符，以英文字母开头，其余可用英文字母、数字和下划线；不区分大小写，保存为小写。同一规范化用户名只能注册一次。
3. 密码为 8–128 个字符，首尾空格计入并原样保留。注册时两次输入必须一致，可用输入框内的显隐按钮核对。无需手机号、短信或邮箱。
4. 注册成功后自动登录，进入“我的账号”查看用户名、登录方式、注册与最近登录时间。返回设置即可继续使用 App。

登录需要可访问账号服务的互联网连接。连接相机 Wi-Fi 时可能无法上网；账号请求与相机队列独立，不会为登录主动断开相机。请求失败时显示原因并允许重试，注册重名、密码错误、账号停用和请求过多分别处理。本轮不含密码找回、密码修改或账号合并。

## 登录状态与退出

普通用户会话有效 7 天，每用户最多保留 10 条。新增会话超出上限时淘汰较早会话；过期后重新登录。App 仅保存会话和必要用户资料，不保存密码；本机会话通过 AndroidKeyStore 密钥加密，位于不参与 Android 备份的应用目录。

重新打开 App 或网络失败时，已保存身份显示“已保存登录信息，待联网核验” / “离线缓存”。打开账号页会核验服务端状态，也可手动刷新；缓存资料不证明服务端会话仍有效。服务端确认会话失效或账号停用后，清除本机身份并要求重新登录，游客功能仍可使用。

“退出登录”先确认手机中的预设、照片和拍摄项目保留，然后清除本机身份并请求撤销当前服务端会话。远端注销失败时明确提示“本机已退出；服务器注销暂未完成”，原服务端会话仍可能持续至到期；本机不会恢复该 token。本机清除失败需要重试，不能当作退出成功。退出当前会话不等于注销所有设备。

后台停用用户会在同一数据库事务中撤销其全部普通用户会话。重新启用后允许重新登录，不恢复旧会话。

## 后台与 QQ 的范围

后台“用户管理”展示用户名、昵称、用户 ID、登录来源、状态、注册 / 最近登录与累计登录。账号密码来源显示“账号密码”；QQ 来源显示“QQ 登录”，QQ 标识仅显示掩码。可搜索用户名、昵称或用户 ID，筛选状态、查看详情并确认启停。后台管理员的账号、权限与会话独立；App 注册账号不会获得后台权限。

QQ 互联应用已申请并由用户确认审核通过 / 已上线，Android 已接入官方 QQ SDK，服务端已配置 AppID `1105984855`。平台登记的 Android 包名与签名仍需和安装包一致，真实 QQ 授权尚待完成验证；账号密码注册 / 登录不依赖 QQ。SDK、隐私流程、服务端验证和平台配置见 [QQ 接入说明](qq-login.md)。

## 服务端接口与凭据

接口前缀为 `/preset-library`，仅通过 HTTPS 使用：

| 接口 | 输入 / 认证 | 结果 |
| --- | --- | --- |
| `POST /auth/register` | JSON `username`、`password` | 创建用户并返回独立 Bearer 会话 |
| `POST /auth/login` | JSON `username`、`password` | 验证后返回独立 Bearer 会话 |
| `GET /auth/me` | `Authorization: Bearer …` | 当前资料及会话到期时间 |
| `POST /auth/logout` | `Authorization: Bearer …` | 撤销当前会话 |

服务端仅保存带独立随机盐的 scrypt 密码哈希及会话 token 的 SHA-256 哈希，客户端不能读取凭据表。用户名和环境级尝试计数在 PostgreSQL 中持久限流；管理员及 QQ 登录使用独立命名空间。密码、完整会话和 QQ token 不应写入文档或日志。
