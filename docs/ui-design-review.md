## 设计依据

统一在线预设库、内置精选与本地文件；每款预设展示配套真实样片；下载到手机后可导入 Z6II 空槽。用户随后增加无线相册，并确认单张或多张下载到手机、本地查看的完整流程。界面面向普通用户，诊断作为辅助入口。

## 候选来源

产品机制：通过照片选择预设，手机负责获取和管理，再用一根 USB 数据线导入相机。常用情境是外出拍摄前后在手机上选择，主界面必须让内容、下载状态和下一步一眼可见。

按共鸣度排列的候选：

1. 摄影展画廊：照片优先，灰白和炭黑，中文无衬线，图片与作品信息稳定对齐。
2. 摄影杂志：白底、黑字和小面积红色，标题紧凑，照片条目连贯阅读。
3. 公园导视：浅色底、深绿，清晰的层级与方向提示，完成阶段一眼可认。
4. 日常生活目录：灰白、深灰与朱红，朴素无衬线，名称和下载状态紧邻照片。
5. 旅行指南：纸白和深蓝，易读的章节与状态，适合离线使用的内容浏览。
6. 数字相册：冷白和中灰，系统字体，紧凑网格用于比较样片。
7. 材料样本册：浅灰与棕红，准确的样本名称和来源，强调逐项辨认。

常见套路为黑黄实验面板；单纯换成极简白色控制面板也不能满足样片浏览任务。候选只提供色彩、字体、密度与一项信息组织特色；导航、按钮和选择均保持原生安卓习惯。

## 审核重点

首页照片大小与列表密度；在线与本地切换是否直观；手机添加入口是否易找；下载和导入是否能分辨；导入确认中的相机、空槽和适配摘要是否足够清楚。

已进行图片层面的内容核对：去掉 B 初稿擅自添加的品牌标志与底部导航；A 将手机添加图标改为文件，并把可下载按钮直接写为“下载”；确认图包含 C8 空槽和兼容适配摘要，成功图区分保存与自动应用。

这些图尚未验证 Android 实机的字号缩放、触控范围、无障碍或运行状态；这些属于审核通过后的实现验证。

审核状态：用户已授权按最近展示方案开发。最终原生实现仍需手机运行与视觉验收；当前不把设计图当作真实运行截图。
