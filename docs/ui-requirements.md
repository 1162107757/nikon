# 界面改版需求

更新日期：2026-10-16。当前为需求草稿，后续条目在此继续补充。

## 1. 首页预设列表与导入入口

### 已确认的需求

- 面向普通用户，减少当前实验工具界面的理解负担。
- 首页展示预设列表，并展示各预设的效果。
- 效果使用该预设配套的真实样片，不在本轮新增照片模拟渲染。
- 列表同时包含内置精选预设与用户从手机添加的预设；第 2 条追加统一在线预设库来源。
- 点击某个预设后，可以选择将其导入相机。
- 首页提供从手机存储选择 NCP 并导入相机的入口。
- 延续 Android 手机通过一根 USB 数据线连接 Nikon Z6II、不拔卡的使用方式。

### 建议的页面与操作流程

| 页面或环节 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 首页 | 精选、在线与本地预设内容；每项显示样片缩略图、预设名称及下载状态；相机连接状态作为简短提示 | 点击预设；从手机选择 NCP |
| 预设详情 | 放大样片、预设名称、来源与简短兼容说明 | 未下载时下载到手机；已可用时导入相机 |
| 导入确认 | 相机名称、预设名称、可用目标槽位、兼容适配设置摘要 | 确认导入 |
| 导入结果 | 成功保存的目标槽位，或失败原因与下一步操作 | 完成；检查相机状态；查看帮助 |

浏览路径：**首页选择预设 → 查看样片 → 导入相机 → 连接检查与选槽 → 确认 → 查看结果**。

手机文件路径：**从手机选择 NCP → 系统文件选择器 → 文件检查并加入本地列表 → 预设详情 → 共用导入流程**。用户取消文件选择时返回原页面。

以上页面划分和文件加入时机属于设计建议，尚未确定最终版式、导航样式或视觉风格。

### 展示与交互要求

- 未连接相机也可以浏览预设和查看样片；在点击“导入相机”后引导连接和授权。
- 本地预设没有配套样片时显示“暂无样片”，仍可进入详情和按兼容情况导入，不挪用其他预设的照片作为效果。
- 样片标注为“示例效果”，不暗示不同场景、机型或适配设置下拍摄结果完全相同。
- 从手机选择文件后，区分“已添加到 App”与“已导入相机”，避免用同一成功提示混淆两步。
- 导入流程自动组织相机识别与槽位读取，用户无需先手动执行诊断操作。实际登记前仍复查槽位。
- 目标只提供可用空槽；不存在空槽时给出可执行的说明，保留所选预设。
- 兼容设置摘要需可见并可修改。目前中等范围锐化默认适配值为 1，清晰度为 0；最终确认前可查看全部适配项。这些是兼容适配值，不标为文件原生参数。
- 确认页集中展示预设、相机、槽位与设置，避免多层连续确认弹窗。
- 传输中按实际阶段反馈状态，防止重复点击；没有进度依据时不展示百分比。
- 正常用户流程采用“预设”用语；必要时注明其对应相机中的“自定义优化校准”。

### 必须覆盖的状态

| 状态 | 用户应看到或能做什么 |
| --- | --- |
| 本地列表为空 | 清晰的添加入口；仍能浏览已有精选内容 |
| 缺少样片 | “暂无样片”，仍能查看预设信息 |
| 文件损坏或格式暂不支持 | 分别说明原因，允许重新选文件，不伪装成导入成功 |
| 未连接、未授权、型号暂不支持 | 对应的操作指引；保留所选预设 |
| 检查相机中、无空槽 | 显示真实阶段；无空槽时停止并允许稍后重新检查 |
| 待确认 | 显示目标相机、槽位和兼容设置 |
| 导入与读回中 | 防重复操作，提示保持连接 |
| 已保存并核对成功 | 明确保存到哪个 C 槽；提示到相机选择并试拍 |
| 写入前失败 | 说明本次未导入，并提供适合该原因的下一步 |
| 已尝试写入但结果未确认 | 提示可能已保存，先重新读取相机状态；不自动重试 |

### 辅助功能安排建议

相机能力读取、目录诊断、原始协议错误、报告导出、旧存储卡试传与机内复制等内容集中到“帮助与诊断”或高级入口。失败页可提供次要的诊断入口，首页不展示长篇技术日志。

### 本条验收要点

1. 打开 App 即可看到预设列表；有真实样片的条目可以查看对应效果。
2. 内置精选与本地添加的预设均可找到，来源能够辨认。
3. 从列表选择预设与从手机选择文件，最终进入一致的导入流程。
4. 不要求用户理解 PTP、目录、事务号等概念即可完成正常导入。
5. 导入保留现有空槽检查、单次登记与读回核对；成功页准确给出目标槽位。
6. 无样片、无连接、无空槽和结果未确认时，都有明确状态与下一步。

## 2. 统一在线预设库与下载

### 已确认的需求

- 增加在线下载预设功能。
- 由应用提供统一在线预设库，用户可在 App 内浏览并获取预设。
- 延续真实样片展示，下载后的预设进入已有的相机导入流程。

### 建议的操作流程

**浏览在线预设 → 查看真实样片与兼容说明 → 下载到手机 → 文件检查并加入本地列表 → 导入相机**。

- 首页可以浏览在线内容，条目明确显示“未下载”或“已下载”；具体分区与导航形式在版式设计时确定。
- 在线预设详情显示名称、真实样片、简短介绍、适用机型或格式范围及文件大小。
- 未下载时主操作为“下载预设”；下载并检查通过后，同一位置变为“导入相机”，避免额外的成功页面。
- 下载无需连接相机，不会因为下载完成就自动写入相机。
- 下载到本地后，离线也可查看已缓存的信息并导入相机。尚未缓存的样片显示对应状态。
- 同一预设内容已存在时使用本地副本，不仅凭相同名称判断重复。

### 下载相关状态

| 状态 | 用户应看到或能做什么 |
| --- | --- |
| 在线内容加载中 | 加载提示，已有本地内容仍可使用 |
| 网络不可用、在线库暂不可用 | 重试入口；继续浏览和使用已下载或本地添加的预设 |
| 尚未下载 | 下载入口与文件大小 |
| 下载中 | 真实下载进度；支持取消，防止重复触发；没有总大小时使用不确定进度 |
| 下载失败、资源失效 | 保留所选预设，说明失败原因并提供重试或返回操作 |
| 下载后检查中 | 检查结束前不进入相机导入 |
| 文件损坏或格式暂不支持 | 与网络失败区分，明确该文件当前无法导入 |
| 已下载 | 已保存到手机；可以进入相机导入，不显示成已导入相机 |

### 本条验收要点

1. App 内能够从统一在线库浏览预设及其真实样片，并完成下载。
2. 下载后的预设能在本地列表找到，并与手机添加的预设共用相机导入流程。
3. 未连接相机时可以完成下载；断网不影响已有本地预设的导入。
4. 清楚区分“下载到手机”与“导入相机”，不会因下载成功而宣称相机已保存。
5. 网络失败、取消、资源失效和文件检查失败都有明确状态，未完成下载的文件不能作为可导入预设使用。

## 3. 相册与无线读取照片

### 已确认的需求

- 增加相册功能，参考尼康无线连接相机、读取照片的体验。
- 首版需要完整流程：无线浏览相机照片，单张或多张下载到手机，并在手机查看已下载照片。
- 本轮先提供设计图供用户审核，审核后再开发。

### 建议的信息结构

- 全局仅提供“预设”和“相册”两个目的地，不为凑导航增加账号等功能。
- “预设”内保留“在线预设 / 我的预设”；“相册”内提供“相机照片 / 已下载”。
- “已下载”表示本 App 下载的照片，不扩大成整个手机照片管理器。
- 预设页面明确 USB 状态；相册页面明确无线状态，避免把一种连接成功误解为两种任务都已可用。
- 新的相册入口适用于三种待选视觉方向；首页旧方案的导航结构需随本条统一更新。

### 建议的页面与操作流程

**进入相册 → 无线连接引导 → 相机缩略图列表 → 查看大图或多选 → 下载到手机 → 已下载列表与本地查看**。

| 页面 | 主要内容与操作 |
| --- | --- |
| 无线连接引导 | 相机开启 Wi-Fi 的步骤；打开手机 Wi-Fi 设置；返回 App 后读取照片；未连接也能查看已下载内容 |
| 相机照片 | 无线连接状态、按日期组织的照片网格、选择模式、单张查看与多张下载 |
| 照片详情 | 大图、文件名与格式；未下载时提供“下载到手机”，已下载时明确本地状态 |
| 下载任务 | 已完成张数与当前状态；取消剩余任务；中断时保留已完成照片 |
| 已下载 | 本 App 已保存的照片列表；断开相机后仍可查看大图 |

### 必须覆盖的状态

- 未连接、连接中、无线已连接、连接失败及重新连接。
- 缩略图加载中、相机没有可显示照片、单项缩略图读取失败。
- 选择一张或多张照片、下载中、用户取消、部分完成、全部完成。
- 下载断线时显示实际已完成数量，保留已完成内容；不把整个任务显示为成功，也不承诺断点续传。
- 手机空间不足或无法保存时，给出明确原因与处理入口。
- 相机缩略图可见不等于文件已保存到手机，不能提前显示“已下载”。
- 相机 Wi-Fi 连接状态与互联网可用状态分开判断；互联网不可用时，在线预设加载失败不应误报为相机断开，本地预设和已下载照片仍可使用。

### 官方参考与开发边界

[Z6II 官方连接手册](https://onlinemanual.nikonimglib.com/z7II_z6II/zh-cn-prc/10_establishing_wireless_connections_03.html)说明 SnapBridge 可无线连接并下载照片；[SnapBridge 官方下载帮助](https://nikonimglib.com/snbr/onlinehelp/cn/downloading_selected_pictures_11.html)描述相机缩略图与照片下载。它们用于设计参考，不证明本 App 已实现无线读取。

本轮设计以 JPEG 演示。无线协议、原图或缩图下载、RAW 与视频、保存到系统相册的细节待开发阶段明确和实机验证。相册功能不改变当前 USB 预设导入路径，也不代表已支持无线导入 NCP。

### 本条验收要点

1. 用户能区分“相机照片”和“已下载”，也能区分无线照片读取与 USB 预设导入。
2. 单张下载与多张下载都能完成；成功保存后能在已下载列表查看。
3. 无线断开后，本地照片仍可查看；中断的任务准确区分已完成与未完成。
4. 页面不会把缩略图缓存或 Wi-Fi 连接成功当成照片下载完成。

## 待继续整理

- 内置精选与在线预设库的首批数量、内容，以及每个预设配套的真实样片尚待确定。
- 统一在线库的资源维护方式、目录服务与文件存储方案尚待确定；用户自填链接、账号、付费和社区不在当前已确认范围内。
- 本地预设的样片添加方式、重名处理及管理操作尚待确定；当前不擅自增加收藏、分类、批量导入等功能。
- 相册的照片格式、下载尺寸和系统相册保存细节待确定；无线读取须单独验证。
- 后续用户需求继续按编号补充；配色、字体与最终版式在需求收敛后设计。
