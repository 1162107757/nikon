# 照片滤镜编辑与逐张设置批量导出

适用版本：0.13.6-beta（74）。用户确认的布局与范围见 [设计需求](design-review/photo-filter-editor-20261019/REQUIREMENTS.md)。74 的在线状态与选择稳定性见[验收记录](validation/photo-selection-polish-74/README.md)与[安装包](../dist/nikon-usb-0.13.6-beta-debug.apk)；72 的相册刷新／导出、70 的完整本地原图编辑资格、71 的来源／分类样式沿用，73 的相机下载恢复与 RAW 修复保留。旧版本证据保持各自范围。

已有完整本地 JPEG 原图时，打开照片即可在暗色大图下方选择滤镜。编辑资格由完整本地原图决定，与相机／已下载／直播标签页或照片来源无关；相机照片下载完成后同样可以编辑。主图保持完整比例，并保留缩放、切图、星标、版本与按住原图对比。对比按钮可见文字为“原图”，辅助功能仍说明按住查看的操作。

相机照片只有预览、尚无完整本地原图时，使用纯浏览全屏布局，保留收藏、底部导出及预览错误原因／重试；此时不挂载滤镜编辑器、不显示强度，也不发起在线预设请求。下载或直播保存完成后重新核对本地原图并更新查看器，符合条件才显示编辑器。切到未下载照片会解除上一张的编辑绑定，避免旧照片的图像或异步编辑结果进入当前查看器。

底部缩略图使用当前照片实际渲染。默认来源为“在线”，可切换“我的”查看当前账号可见的本地预设。“全部”展开搜索与三列网格，展开面板同样支持来源和分类切换。不支持的预设提供原因，不能假装应用成功。

## 在线来源、分类与离线使用

在线目录来自应用统一管理的 HTTPS 预设库，分类沿用发布数据。筛选顺序为人像、风景、胶片、黑白、日常、夜景，只展示该来源实际存在的分类；其后保留额外自定义分类与未分类。切换“在线／我的”清除当前分类和搜索，回到该来源起点。

生产库已将 241 份预设归为人像 27、风景 79、胶片 52、黑白 21、日常 54、夜景 8。分类是选用建议，不限制拍摄题材；依据、无法测量的配方与事务核对见[分类整理记录](preset-category-classification-20261020.md)。

目录加载使用独立工作线程；可见缩略图及点击选择时才按需读取真实 NCP／NP3 配方。每份配方核对声明长度、SHA-256 和实际容器格式，再使用现有手机近似模型渲染。浏览或应用只写照片草稿，不自动添加到“我的”，也不覆盖同 SHA 本地预设的自定义分类。

网络失败可回退同一服务经过重新验证的目录缓存，并明确标注缓存状态。已经读取的配方保存在独立、有界的预览缓存中；未缓存配方仍需联网。无目录缓存时显示失败与轻点重试，缩略图取配方失败也可重试，不用模板或假效果冒充成功。在线缓存与显式下载到“我的”分别处理。

74 的底栏与展开层共用简短状态：失败为“在线滤镜加载失败 · 轻点重试”，缓存为“离线缓存 · N 款 · 轻点刷新”。完整错误及缓存限制放在长按提示中；加载、空列表与正常数量仍分别展示，不用长主机名挤掉重试文字。

## 选择稳定性与材质

71 将“在线／我的”合为视觉高 32dp 的轨道，选中面片为中性 28dp，触摸范围仍为 48dp；整组与“全部”间隔 12dp。分类选中为蓝字加 18×2dp 短下划线，替代大胶囊；标题行与分类间距 6dp，分类项间隔 6dp，固定 13sp 中等字重，选中不改变文字宽度。展开面板同样式，并在分类集合不变时复用子控件，减少刷新闪动。

横条按配方身份保留卡片 View，点击与异步缩略图返回只更新选中态、图像和文字；横条点击不修改滚动位置。展开网格选中后，仅在目标不可见时作最小滚动。切照片重新建立条目，旧照片或账号的异步结果按代次失效。缩略图队列满时，当前选择有四次有界延后重试，后续实际任务完成继续优先处理当前选择。

底栏采用当前照片的预模糊取样、深色衬底及顶部高光，外圆角 26dp。横条卡片为 84×110dp，图像高 78dp、名称高 26dp；目录状态行固定 28dp、底部编辑提示固定 24dp，长文字单行省略并保留完整提示，避免加载或长名称撑高底栏。控件保留原生触控、安全区和横屏右侧布局。

展开选择器竖屏高约屏幕 72%，横屏约 90%。大字号下“在线／我的”保持单行；横屏将来源按钮放到标题行，搜索与可横滑的分类合并为一行 48dp，保留完整网格图像及名称行。来源切换不恢复旧来源的滚动位置。

强度为 App 自身的 0–100% 混合，0% 回到原图，100% 使用现有完整配方模型。预览与完整尺寸导出共用编码 sRGB 混合规则；手机效果仍为近似模型，本次没有新增与 NX Studio 的色彩标定。

## 单张与批量操作

右上导出按钮的可见背景为 64×36dp，实际触摸范围为 64×48dp，使用 13sp 单行文字。已下载页用顶部下拉取代刷新按钮；相机页的分页状态位于列表底部，加载时转圈，失败可点按重试，到底显示“已加载全部照片”，中段浏览时隐藏。成功追加保留原列表；紧凑横屏状态位于右下，普通高度在下方居中。

1. 为照片选择滤镜并调节强度。操作只更新预览和私有草稿，不立即创建效果图或系统相册副本。
2. 返回后继续设置其他照片。重进照片会恢复各自的设置；草稿按账号和校验后的原图内容保存，并保留配方原字节快照。
3. 单张点右上“导出”，核对效果、强度和原始像素尺寸，再保存到相册。
4. 批量时，在已下载或直播项目中多选，点“批量导出”／“导出”。每张照片使用自己的未导出草稿；没有未导出草稿时保留所选已保存版本。已导出的设置是历史记录，不覆盖后来选择的原图或旧效果。

JPG 沿用完整尺寸、JPEG 95、sRGB 和捕获信息保留策略。原图不改写；效果加入原照片版本。单张导出完成时显示并记住该保存结果；处理中产生的新编辑仍保留。版本菜单可暂时查看保存版本，未导出草稿保留并可点按底部提示恢复。重复导出相同原图、配方、强度和模型会复用已验证结果，并核对／恢复系统相册副本。

开始时冻结每张图的设置，之后的新编辑不会改动已排队任务。部分失败保留成功项，提供仅重试失败和未处理项的操作；重试沿用该次冻结的设置。最多一次 100 张，可停止后续处理。

NEF 是次级原文件导出，不带手机滤镜。连接富士时不提供 Nikon NEF 获取能力；离线已有 NEF 沿用原有发布规则。相机返回 0x2013 表示存储不可用，不能据此断言没有 RAW，详见 [富士验证记录](fujifilm-raw-export-validation-20261019.md)。
